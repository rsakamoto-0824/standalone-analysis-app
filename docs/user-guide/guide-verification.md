## 画像の出所と限界

アプリの参考画像はMATLAB R2022b / macOSで、製品の `AnalysisController.m` を一時コピーして表示しました。コピーの起動時リリース確認だけを表示用に置き換え、操作コールバックは無効化しました。学習・推定・SHAP・DOE・モデル保存は実行していません。製品ソースのリリース確認と計算・保存関数は変更していません。

指標、要約統計、単語件数、ワードクラウドは説明用データをR2022bで計算した値です。成功したモデル保存後検証の画面は作成せず、検証表は空欄で撮影しています。

App Designerの追加の実画面撮影は端末ロック中に行えなかったため、StartupFcnの操作位置を示す2枚は公式資料の掲載例を使用しました。各画像の直下に出典・掲載ページのリリース（R2026b）・参考用途を明記しています。
