Windowsでの入力、学習、比較、保存と各機能の操作を示す。

Windowsでの入力、学習、比較、保存と各機能の操作を示す。

製品：Process Insight Tool。基準コミット：df9ffc2214c6196eefb389f890d25551d53f2b1d。文書の版と製品バージョンは別管理です。

作業前の確認

対象はWindowsの利用者です。入力の単位・目的変数・Run、出力先を確認します。同梱のsamples/ProcessInsight_Samples.xlsxで操作を試せます。左のメニューは1〜8、設定は7、Helpは8、モデルを使う画面は5です。

掲載画像はアプリ内部だけの操作参考です。実環境のWindows上での合格証跡ではありません。OSのウィンドウ枠や閉じるボタンを含めていません。

① データを開く

左でAPC・Swing Curve・汎用回帰を選び、①でExcel / CSVかサンプルを開きます。シートとヘッダー行、先頭の値を確認してください。

操作位置：中央上の「Excel / CSVを開く」→「シート」「ヘッダー行」。一覧は先頭100行で、学習は全行を使用します。

② 目的変数と説明変数

左側で目的変数を選びます。複数選択はCtrlを押しながらクリックします。APCは4変数へ入力列を割り当て、汎用回帰は説明変数と順序を指定します。

操作位置：左の目的変数 → 右の説明変数 → 右下の順序表と「上へ／下へ」。目的変数と同じ列を説明変数へ入れません。

Swing Curveでは下地なし／下地ありを選び、膜厚列と必要な下地列を指定します。実行時に数値・空欄・重複等を検証し、誤りがあれば②へ戻ります。

操作位置：右上「モード」→「レジスト膜厚の列」→下地の一覧。最下部の順序表でRESIST_THが最後であることを確認します。

③ 条件を決めて実行

GPRカーネル、汎用回帰では方式・PLS成分数・木の本数を選びます。初期は交差検証なしの学習データ評価です。未知データの目安を比較する場合は交差検証を選びます。SHAPは省略し、後から計算できます。

操作位置：左のカーネル一覧 → 右の交差検証とSHAP → 右下の実行ボタン。Fit methodは「7 設定」で変更します。

④ 結果を比べて保存

目的変数・条件・評価データの範囲（Scope）を確認して行を選びます。R²・RMSE・残差・SHAP・重要度を確認し、必要に応じて条件を変更して比較します。最後に採用モデルを保存します。

操作位置：上のモデル行 → 下の評価・グラフ →「選択モデルをMAT保存」。保存後検証を確認します。「予測・SHAPを1ファイルに保存」で元入力と結果を出力できます。

保存モデルで推定・SHAP

左の5でMATまたは起動中モデルを選び、推定データを開いて保存モデルの入力順へ割り当てます。実測列は任意です。SHAPを選んで実行し、分布・入力別依存図を確認します。色の変数も変更できます。

操作位置：左の①モデル → ②データ → ③割当 → ④実行。右側で結果を見る。炉内補間のFurnace_Modelをこの画面に読み込ませません。

炉内補間

4でWaferId・BoatSlot・計測列・任意バッチを指定し、予測範囲と6方式を選びます。Runを混ぜず、目的変数ごとの検証RMSEと曲線を確認します。外挿は必要な場合だけ有効にします。

操作位置：左の方式一覧 → 右のSlot範囲 → 必要な場合だけ外挿 → 実行。④で選んだRun・項目・方式を専用MATへ保存します。

実験計画・設定

6でD最適・I最適・直交表を選び、因子数・モデル・水準・実験数を設定します。値は−1〜1の符号化値です。生成したら交絡・ランク・効率も確認します。

操作位置：左で方式とモデル等を選び「実験計画を作成」。右の評価指標と交絡を確認。実単位への換算表は別途保持します。

7で保存先・テーマ・文字サイズ・GPR Fit method・ビン数・DOE seed・RBF条件を変更し、「設定を保存して適用」を押します。

操作位置：必要な設定項目 → 左下「設定を保存して適用」。変更は次回の実行へ反映し、学習済みの履歴は消しません。

完了確認と困ったとき

終了前に使うモデルをMAT保存し、出力表・採用条件・評価範囲を保管してください。入力の誤りは表示された列・元行を確認します。保存後検証に失敗したモデルは使用せず、障害対応を参照します。用語は「8 Help」で確認できます。
