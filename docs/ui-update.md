- 左の機能タブは APC、スイングカーブ、汎用GPR、保存モデルで推定、SHAP、実験計画作成、ワードクラウド、設定、Help の9個。

## 評価と要約

従来7指標（RMSE、RMSPE、MAE、Pearson r、rの2乗、KL、相互情報量）を一括計算し、通常の決定係数 R² も追加する。

- R² = 1 − SSE/SST。負値も表示する。従来の `calc_r_squared` は相関係数の2乗のまま維持し、別名で表示する。
- RMSPEで実測0、定数列で相関・R²が未定義などの場合、その指標だけ NaN と理由を表示し、他の指標を残す。
- KL は実測分布から予測分布への向きで nats、MI は bits。ビン数0は既定の自動計算。両者の擬似度数1は既存実装を維持する。
- 割当入力、実測、予測、残差について11項目の要約を自動作成する。学習入力の欠損値は従来どおり拒否する。

## 実験計画（ユーザー確認済み）

直交表は2水準または3水準の同一水準系。混合水準は対象外。I最適は領域 −1〜1、拡張は既存点を固定して D/I で追加する。

- D/I は各因子 −1/0/1 の候補を使い、4初期点・最大12巡の座標交換で探索する。大域最適性は保証しない。反復点を許す。
- D は −log det(X'X) を最小化する。
- I は連続な一様領域 [-1,1]^k の積分予測分散 trace((X'X)^−1 B) を最小化する。B は単項式の積の厳密な一様分布モーメントから求める。候補点だけの平均を I 基準と呼ばない。
- モデルは linear（切片＋主効果）、interaction（＋2因子交互作用）、quadratic（＋平方項）。モデルの項数以上の行数とフルランクが必要。
- 直交表は素数水準の射影構成（強さ2）で必要サイズを自動選択する。2水準L4/L8/L16、3水準L9/L27。実験数欄は使わない。直交表は選択モデルのフルランクを保証しない。
- 因子数1〜8、追加数1〜300、既存＋追加500行以下。seedは必須の非負整数。同じコード・環境・入力・seedで再現する。呼出前の乱数状態を復元する。
- 拡張は既存ファイルの因子列を画面で割り当てる。−1〜1への符号化は利用者が事前に実施する。既存点は値・順序とも維持し、追加点を後ろに並べる。
- 二次モデル項の正規化内積の絶対値をヒートマップ表示。対角線以外の1は2項の完全交絡、0は直交。0ベクトル項は空白。複数項の依存は零空間の係数表（各列の加重和が0）とランクで示す。一般のエイリアス行列とは区別する。

## SHAPスイング近似の追加（2026-10-28）

RESIST_TH のSHAP依存図に `c + m(t−t0) + A sin(2π(t−t0)/T + φ)` を近似する。t0は対象範囲の中点、Aは片振幅。直線トレンドmを画面でオン/オフできる。近似評価のR²は1−SSE/SST、RMSEはSHAP散布点との誤差であり、GPRモデル評価とは区別する。

- `fit_swing_curve` は周期だけを探索する。各候補のオフセット・直線・sin/cos係数をQR分解で最小二乗推定する。xと応答をスケーリングし、元の単位へ戻す。Curve Fitting Toolbox / Optimization Toolboxは追加しない。
- 自動の周期範囲は `[max(4×膜厚点間隔の中央値, 対象幅/20), 対象幅]`。手動指定も可能。対象幅を基準にした周波数を401点以上、無次元周波数の刻みを最大1/80として走査し、局所最小をfminbndで細分化する。探索下限・上限も候補に含める。大域最適性や物理的な周期の正しさを保証しない。
- 異なる膜厚8点以上、有限な数値が必要。同一膜厚の繰返しは観測行ごとの同じ重みで扱い、行順を変えても近似できる。定数・直線のみで周期成分を識別できない場合は周期を出さない。手動設定でも対象幅内の最大100周期まで。短い周期の取り違え、低いR²、探索境界、1周期未満の範囲を画面で通知する。
- 膜厚下限/上限は読込データ内に限定し、その範囲の点で再近似する。ズームだけでは対象点・表を変更しない。
- 極値は `m + (2π/T)A cos(2π(t−t0)/T+φ)=0` を解く。正弦波だけの頂点位置は使わない。範囲内の真の極大・極小だけを描画し、端点を便宜的に極値にしない。`abs(m) >= (2π/T)A` なら厳密な極値はない。
- 同種の極値を膜厚順に並べ、隣接する2点を結ぶ線と `(SHAP2−SHAP1)/(膜厚2−膜厚1)` を表示する。この一定振幅＋直線モデルでは、山間・谷間・全区間の傾きはmと一致する。区間ごとに変わる振幅や傾きを評価するモデルではない。
- 24個以下の極値は膜厚を図中に注記し、全ての極値と隣接傾きは表に残す。同種極値が2個なければ隣接傾きなし。近似指標表に膜厚・周期範囲、トレンド選択、位相と基準膜厚も記録する。
- `SwingCurveView` をRESIST_TH依存図の内部へ組込み、指標・極値・傾きの表を切り替えて保存する。グラフはPNG出力の対象。設定を変更すると古い近似と表を消去し、再更新する。
- スイング学習に任意のSHAP計算チェックを追加（既定オフ）。保存・検証成功後、先頭最大1000行でSHAPを計算し、GPR評価結果を保持してSHAP値を別表に出す。既存の学習・MAT保存コードは変更しない。

参照：[fminbnd](https://www.mathworks.com/help/matlab/ref/fminbnd.html)、[局所探索の制約](https://www.mathworks.com/help/matlab/math/optimization-troubleshooting-and-tips.html)。2026-10-28参照。

## スイング近似残差の診断（2026-10-29）

`swing_residual_diagnostics` で、選択した膜厚範囲の各観測行について `残差 = SHAP値 − 近似値` を計算する。GPRの実測値−予測値の残差とは区別する。同一膜厚の繰返しを平均化せず、近似に使った各行を診断に用いる。

- アプリ内の「近似カーブ」「残差分布」「正規Q–Q」「残差対膜厚」を切り替える。分布図は確率密度に正規化したヒストグラムへ、標本平均と標本標準偏差（n−1）による正規密度を重ねる。ビン数はMATLABの自動設定で、検定・歪度・尖度はビン分け前の残差から計算する。
- 正規Q–Qは `norminv((i−0.5)/n)` と、`(残差−残差平均)/残差標準偏差` の昇順値を比較し、基準線y=xを表示する。残差対膜厚では0線からの偏り、残った周期性、膜厚によるばらつきの変化を確認する。
- Lilliefors検定（`lillietest`、正規分布族、α=0.05）で平均・標準偏差が未知の正規分布への適合を検定し、判定・p値・検定統計量・臨界値を表示する。棄却できない場合は「正規性を棄却できず」と表示し、「正規分布である」とは断定しない。
- p値はMATLABの事前計算表の補間を使う。表の下端0.001以下、上端0.5以上は `p <= 0.001` / `p >= 0.5` として記録し、境界値を正確なp値として扱わない。表外p値の既知の警告だけを抑え、元の警告設定を復元する。Monte Carloの乱数は使わない。
- 歪度は `skewness(z,0)`、尖度は `kurtosis(z,0)` で偏り補正する。ここでzは中心化・標準化残差。正規分布の基準は歪度0・尖度3。超過尖度は尖度−3で基準0。尖度は裾や外れ値の影響を受ける4次モーメントであり、分布の頂点の鋭さだけを表すものではない。
- 残差標準偏差が `max(1e−7×SHAP標準偏差, 100×eps(入力SHAP・近似値の最大絶対値))` 以下なら、周期探索の数値誤差を分布として検定しない。判定は対象外、p値・歪度・尖度・標準化残差はNaNとし、理由としきい値を表に残す。ヒストグラム・生の残差対膜厚は残し、Q–Qは対象外と表示する。
- 「残差の正規性」表は検定名・件数・有意水準・判定・p値の境界・形状統計・注意事項をCSV/Excelへ出力する。「残差データ」はSHAP入力内の行番号InputRow、膜厚、SHAP値、近似値、残差、標準化残差を出力する。InputRowは元CSVの物理行番号とは異なる。図はそれぞれPNGへ保存でき、入れ子のタブを表示してから書き出す。
- 膜厚・周期・トレンドを変更すると診断図と表を消去し、「近似を更新」で再計算する。設定変更前の診断を残さない。

近似に使用したデータの残差は、係数・周期の推定やSHAPの計算によって依存し得る。Lilliefors検定の独立同分布という前提に対して、再近似を含む検定分布の補正は行っていない。このためp値は参考診断と明示する。少数標本では非正規性を検出しにくく、大標本では小さなずれでも棄却し得る。正規性と、残差の独立性・等分散性・曲線モデルの妥当性は別に確認する。

参照：[lillietest](https://www.mathworks.com/help/stats/lillietest.html)、[skewness](https://www.mathworks.com/help/stats/skewness.html)、[kurtosis](https://www.mathworks.com/help/stats/kurtosis.html)、[norminv](https://www.mathworks.com/help/stats/norminv.html)。2026-10-29参照。追加製品は既存のStatistics and Machine Learning Toolboxの範囲。

## 周期カーネルの追加（2026-10-29）

スイング学習だけに `swingperiodic` を追加する。ユーザー確認済みの周辺尤度による内部最適化を使い、周期Pを `KernelParameters` / `OptimizeHyperparameters` の探索変数やユーザー入力欄に含めない。既存7カーネルの学習本体は維持し、新しい選択時だけ `train_swing_periodic_model` へ分岐する。既存モデルの公開範囲や保存変数名を変更しない。

標準化した入力を u=(SIN_TH,SIN_RN,NSG_TH)、z=RESIST_TH として、カーネルは次の和とする。

```
B(u,v) = exp(−0.5 Σ_j ((u_j−v_j)/ℓ_j)²)
Q(z,w) = exp(−2 sin²(π(z−w)/(P/s_t))/ℓ_p²)
k = σ_b² B + σ_p² B Q + σ_l² z w
```

Bは他3変数の滑らかな影響、BQは条件によって寄与が変わる膜厚の周期成分、最後の線形カーネルはバルク効果を想定した膜厚トレンド。和・積を構成する各成分は正半定値。GPRの基底関数は従来同様の既定constant、Standardize=trueを使う。s_tは学習データの膜厚標準偏差で、Pは入力の膜厚単位のまま保持する。s_t<sqrt(eps)の場合はMATLABの標準化と同じく1を使い、学習後にモデルのPredictorScaleとの一致を検証する。

各周期でGPRが学習するthetaは、ℓ_1, ℓ_2, ℓ_3, ℓ_p, σ_b, σ_p, σ_lの対数7個。数値計算では対数値を−30〜30に制限してexpのオーバーフローを避ける。周期はこの7個とは別に固定する。ノイズ・基底係数もfitrgpが通常どおり学習する。独自のCurve Fitting / Optimization Toolboxは追加しない。

- 周期範囲は `[max(4×異なる膜厚点間隔の中央値, 膜厚幅/20), 膜厚幅]`。異なる膜厚8点以上が必要。外側の無次元周波数探索で9候補を評価し、正弦波近似から得た周期・半分・2倍が範囲内なら追加する。正弦波近似は候補の追加だけに使い、採否はGPRの周辺尤度で決める。
- 初期候補の上位3点それぞれの近傍をfminbndで最大12評価ずつ探索する。合計最大48評価。各候補で7カーネル量などを同じ初期値から学習し、最大のLogLikelihoodを持つ実際のモデルをそのまま採用する。再学習した別のモデルへ置き換えない。局所解や候補密度の影響があり、大域最適性は保証しない。
- exactは全データの周辺対数尤度、sd / sr / ficはそれぞれの近似周辺対数尤度を比較する。近似法では全行から等間隔の行番号で最大1000点のActiveSetを一度決め、同じ部分集合で周期を比較する。最終モデルのXとNumObservationsは全入力行を保持する。
- 呼出元の乱数状態を保存・復元し、各候補は同じ状態から開始する。候補の学習に失敗した理由は探索表へ記録し、他候補を続ける。全候補失敗時はモデルを返さない。探索境界、評価回数による打切り、一部失敗、周期による尤度差が小さい場合を警告する。
- 進捗と中止ボタンを表示する。中止は進行中の1候補の学習が終わった後、次の候補に移る前に反映する。中止時のモデル保存は行わない。
- 周期・範囲・尤度・評価回数を左欄へ表示し、「周期の最適化」表とアプリ内のグラフを追加する。表はCSV / Excel、図はPNGへ保存できる。履歴は実行画面・書出し表の情報で、MATには履歴変数を追加しない。入力や設定を変更すると古い結果と周期表示を消去する。
- `make_swing_periodic_kernel` は固定した式へ検証済み数値だけを埋め込み、str2funcで作成元ファイルへの参照を持たない匿名関数を作る。式に外部入力のコードや名前を連結しない。外部の独自mファイルを呼ぶカーネルはMATへ保存しない。数値7要素の引数は共分散計算、文字列の独自照会は保存済み周期の読出しに使い、functions(handle).workspaceの内部表現に依存しない。MAT内は完全なRegressionGPのTrain_Modelだけ。保存前後で周期・カーネル量・予測の一致を確認する。
- 設定にSwingKernelを追加し、APC・汎用GPR用のKernelと分ける。旧設定にSwingKernelがなければ旧Kernelの値を引き継ぐ。保存モデル推定・SHAPでもMAT内の周期を表示する。

GPRカーネルの周期と、後処理のSHAP散布点への正弦波近似の周期は、対象と目的関数が異なる別の結果であり、一致を保証しない。周辺尤度も学習時の基準であり、未知データへの予測性能は別に確認する。R2025bでの実モデル、別PCの制御側、Windows Compiler / Runtimeでの最終検証は未実施。
