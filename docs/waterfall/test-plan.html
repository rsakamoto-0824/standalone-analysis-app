PIT-05 / 単体・結合・総合・受入

試験計画・試験仕様書

本書の要求を対象に、手順・期待結果・証跡と判定を定める。

文書版1.0・新規作成作成者：坂本2026-11-23確認・承認前

基準：df9ffc2 ／ 現行実装を文書化した初版。Windows R2025b／Runtimeの受入は未完了です。

文書管理情報

本書の要求を対象に、手順・期待結果・証跡と判定を定める。

製品：Process Insight Tool。基準コミット：df9ffc2214c6196eefb389f890d25551d53f2b1d。文書の版と製品バージョンは別管理です。

試験方針

段階対象証跡
単体数値・入力・モデル・保存テスト名、日付、環境、成功・失敗・未実施。
結合入力→列選択→学習→比較→保存→再読込み試験ID、データ、画面、Status / Note、実SHAPか代替か。
総合Windows R2025bで生成し、MATLABなしPCへ導入OS・Runtime更新版、配布物ハッシュ・manifest・操作結果。
受入代表業務データ・旧モデルの互換と精度目的変数・単位・閾値・対象範囲、係長確認・課長承認。
他環境の補助確認・代替SHAPの表示確認を、Windows R2025bでの実SHAP・Runtimeの合格へ読み替えません。

R-002		入力2目的変数を選び、説明変数の重複・目的変数との重なり・欠損・Inf・文字を与える。目的変数ごとにモデルを作り、不正値は列・元行・理由を示して停止する。
T-03
R-003		境界APCを24・25・149・150行で実行し、列順を確認する。24行で停止、25〜149行で注意、150行で行数注意なし。4列順を保持する。

R-004		画面結合Swing Curveの下地なし／ありを切り替え、膜厚・下地を別の列へ割り当てる。下地なしは1入力、ありは選択した下地と最後のRESIST_TH。割当が学習へ反映する。

R-006		検証CVなし／5分割CV、1条件／複数条件、2目的変数で実行する。Scopeを区別し、CVでは各検証行を学習へ含めない。目的変数ごとに順位を表示する。

R-007		数値完全一致・偏り・一定実測・実測0を含むデータで独立計算と照合する。R²とr²を区別し、未定義はNaNと理由。設定のビン数を反映する。

R-008		保存・互換各方式を選択保存し、MAT変数・属性・予測を読み直す。保存もキャンセルする。1モデルだけを再学習せず保存・検証する。キャンセルでも画面のモデルと結果が残る。

T-10
R-010		出力CSV・Excel・PNG・コピー、色の変更、SHAPの未計算行を確認する。元行の対応と評価値を維持し、未計算SHAPはNaN。画像・表が選択モデルと一致する。
T-11
R-011		炉内2Run・2目的変数・6方式で実行し、未計測・重複Slot・計測5点未満を入力する。Runと目的変数を混ぜない。未計測は項目別に除外し、重複と5点未満は停止する。
T-12
R-012		炉内保存内部Slot検証、外挿オフ／オン、GPR区間、6方式のMAT往復を確認する。端点を留め置かず、RMSE棒は目的変数別。範囲外を明示し、予測と区間が保存前後で一致する。
T-13
R-013		実験計画D/Iと2〜5水準の直交表を生成し、既知計画の効率・交絡・予測分散と照合する。因子・行数・水準の制限を守り、ランク不足と未定義指標に理由を表示する。
T-14
R-014		重要度既知の効果のデータでPermutation ImportanceとPLS VIPを計算する。効果の大きい列が高くなり、同じ条件で再現する。因果効果として説明しない。
T-15
R-015		探索表示単変量のグラフで量的／質的な横軸・色の列を選ぶ。点数・カテゴリ・要約が入力に対応し、色の変更が学習や評価の値を変えない。
T-16
R-016		設定Fit method・ビン数・seed・RBF・文字サイズを変更して再起動。不正なJSONも入力する。保存値を反映し、Fit method等は設定だけで編集。読込み失敗時は初期値と警告を表示する。
T-17
R-017		操作進捗・中止・エラー・リサイズ・設定後の履歴選択を確認する。処理後にロック解除し再実行できる。結果とグラフをアプリ内で確認できる。
T-18
R-018		Runtime受入Windows R2025bでビルド後、MATLABなしのPCへRuntime同梱インストーラーをオフライン導入する。起動、8メニュー、サンプル、実SHAP、保存・再読込み、終了・再起動に成功する。
T-19
R-019		受入・互換利用者の旧／新モデルを同じXcheckで比較し、ログとファイル管理を確認する。属性・入力順・予測差の合意を得る。実データやログを外部へ自動送信しない。

実行と記録

Windows R2025bと必要製品で基準コミットを展開し、試験用フォルダで実行します。開発用例外を受入に使用しません。run_testsはプロジェクトの自動試験を実行するため、本書の要求に対応する結果を抽出して記録します。本書の19項目は画面・対象環境の手動確認も含み、自動試験の件数とは別です。

setup_paths;
results = run_tests;
fprintf('Passed=%d Failed=%d Incomplete=%d\n', ...
    sum([results.Passed]), sum([results.Failed]), sum([results.Incomplete]));

試験IDごとに、実施日・担当・環境・入力・実結果・証跡パス・関連不具合IDを記録します。実行していないものは未実施とし、仮定によるスキップも成功へ数えません。

実装根拠：run_tests.m、tests/assume_target_release.m

判定と再試験

  1. 数値許容差は既存の関連テストを正本とし、MAT保存前後の予測一致を確認する。
  2. 失敗を修正したら該当試験と影響する画面・保存・計算の回帰試験を実施し、旧結果も保持する。
  3. 精度と処理時間は目的変数・入力規模ごとの合意値で判定する。未合意の値を本書で捏造しない。
  4. Windows／Runtime・実SHAP・旧制御側互換と高リスクを確認し、係長が技術確認、課長が受入と配布を承認する。
