START HERE

  2. Excel で複数のシートがある場合は、同じ画面の シート で選びます。
  3. 列名が1行目でない場合は ヘッダー行 の番号を変えます。変えるとすぐに読み直します。

手元にデータがない場合は サンプルデータを開く で、同梱の合成データを開けます。

08

USER · MODELING

学習：モデルを評価・比較して保存する

「1 APC 学習」「2 Swing Curve学習」「3 汎用回帰学習」は同じ進め方です。上のタブを左から ① データを開く → ② 変数を選ぶ → ③ 条件を決めて実行 → ④ 結果を比べて保存 の順に進みます。①は7章を参照してください。

8-1② 変数を選ぶ

  1. 左の 目的変数 で、予測したい列を選びます。複数選ぶと列ごとに別のモデルを作ります（最大20列。Ctrl を押しながらクリック）。目的変数は自動では選ばれません（列名が CD・y・膜厚・屈折率のときだけ初期選択します）。
  2. 右の 説明変数 を、下の表のとおりに選びます。
  3. 右下の「モデルへ渡す順序」の表で、変数の名前と順序を確認します。
  4. 確認のボタンはありません。実行したときに、数値でない値・空欄・列の重複・目的変数との重なりを自動で確認し、問題があれば理由を表示して「② 変数を選ぶ」に戻ります。
機能説明変数の選び方
1 APC 学習SIN_TH・SIN_RN・NSG_TH・RESIST_TH の4変数それぞれに、入力ファイルの列をドロップダウンで割り当てます。列名が同じ場合は自動で選びます。保存するモデルの変数名と順序は固定です。
2 Swing Curve学習モード で「下地なし（膜厚のみ）」か「下地あり」を選びます。レジスト膜厚の列 を選び、下地ありのときは 下地の説明変数 を一覧から複数選びます。膜厚（RESIST_TH）は必ず最後の説明変数になります。
3 汎用回帰学習入力に使う列を一覧から複数選びます。順序を変えるときは、下の表で行を選んでから ▲ 上へ / ▼ 下へ を押します。GPR の MAT は列名を持たないため、この順序（1列目、2列目…）で入力と対応します。

確認：左下に緑の文字で「選択中：目的変数 ○列 / 説明変数 ○列」と表示されること。

8-2　③ 条件を決めて実行する（複数条件の比較）

  1. 左の GPRのカーネル を選びます。複数選ぶと比較します（Ctrl を押しながらクリック）。汎用回帰では 回帰方式（GPR・重回帰・PLS回帰・ランダムフォレスト・バギング木）も選べ、PLS を選ぶと PLSの成分数 を、ランダムフォレストかバギング木を選ぶと 木の本数（10〜1000、初期値100、両方で共通）を入力できます。ランダムフォレストは分岐ごとに説明変数の約1/3だけを候補にし、バギング木は全変数を候補にします。どちらも復元抽出に乱数を使い、学習範囲の外では予測がほぼ一定になります。
  2. 右で評価の方法を決めます。初期状態では交差検証を使わず、学習データでの当てはまりで評価します（条件をいくつ選んでも、この方法で比べられます）。
  3. 交差検証で評価する にチェックを入れると、同じ分割の交差検証（学習に使っていない行での予測）で評価します。分割数の初期値は5、乱数seedは0です。
  4. SHAPも計算する を外すと、SHAP を省いて速く終わります。SHAP は④で後から計算できます。
  5. 下の緑の文で、学習するモデルの数（目的変数 × 条件）を確認し、モデリング・SHAP評価を実行 を押します。処理中は進捗を表示し、中止もできます。

GPR の Fit method は「9 設定」で指定した値を、すべての GPR に共通で使います。この画面では変更しません。

i

検証の範囲と計算量

交差検証の指標は、全行の検証予測をまとめて計算します（分割ごとの平均ではありません）。条件ごとに「分割数＋1」回の学習を行うため、条件や目的変数が多いほど時間がかかります。APC は各分割の学習に25行以上が必要です。行をランダムに分けるため、ロットや時系列のまとまりは分離しません。比較に使った検証値は条件選びにも使っているので、採用後は別のデータでも確認してください。

8-3④ 結果を比べる

  1. 上の一覧に、学習したモデルが1行ずつ並びます。行をクリックすると、下に評価とグラフを表示します（選んだ行は青く表示）。
  2. 「順位」は、同じ実行・同じ目的変数の中で RMSE が小さい順です。「評価データ」が「学習データ」の行は、学習に使ったデータでの当てはまりです。
  3. 下の グラフ で、実測値と予測値・残差・条件の比較（RMSE）・SHAP を確認します。実測値と予測値・残差は1つのタブに横並びで表示し、「色を指定する列」で入力ファイルの任意の列により2つの図をまとめて色分けできます。SHAP 依存図は上の「色の変数」で、点の色に使う説明変数を選び直せます。
  4. 表のタブで、評価指標（8指標）・検証分割・予測・SHAPの出力（元データの説明変数・目的変数と予測値・残差・SHAP値を並べた表）・列の要約を確認できます。予測・SHAPを1ファイルに保存 で、この表を CSV / Excel の1ファイルに保存できます。
  5. 条件を変えて③をもう一度実行すると、以前の結果を残したまま一覧へ追加します。

グラフを広く見たいときは グラフを大きく表示 を押すと、一覧をたたみます。一覧はアプリを終了すると消えるため、使うモデルは終了前に保存してください。

確認：一覧の「状態」が成功で、見出しに RMSE・R²・件数が表示されること。失敗した行は「備考」に理由が表示されます。

再学習や SHAP の再計算は行わず、全データで学習済みのそのモデルを保存します。GPR の MAT に入る変数は Train_Model だけです。重回帰・PLS は別形式の Regression_Model で、GPR 専用の制御側へは渡しません。

8-5　Swing Curve向けの周期カーネルを選ぶ（Pro版のみ）

Pro版の Swing Curve学習では、③でカーネルに swingperiodic を選べます（通常版には、このカーネルと周期の探索範囲の欄はありません）。レジスト膜厚の周期成分と、膜厚の直線的な変化（バルク効果を想定）を組み合わせた専用カーネルです。周期は入力しません。右の 周期の探索範囲 の中から、GPR の当てはまり（周辺尤度）が最も大きい周期を内部で選びます。

  1. 露光波長（初期値 248 nm）とレジスト屈折率（初期値 1.77）を確認します。基準周期は「波長 ÷ 屈折率 ÷ 2」（レジスト膜内の定在波の周期）で、初期値では約 70.06 nm です。
  2. 探索範囲は基準周期の 75〜125%（初期値では約 52.54〜87.57 nm）です。探索範囲を自分で指定する にチェックを入れると、下限と上限を入力できます。
  3. 実行後、④の 周期の最適化 の表と「周期探索（周辺尤度）」のグラフで、候補ごとの値と採用した周期を確認します。

候補の周期ごとに GPR を学習し直すため（最大48回）、通常の学習より時間がかかります。交差検証では各分割の学習データだけで周期を探索し直します。周期はモデルの中に保持し、MAT には従来どおり Train_Model だけを保存します。大域的に最良の周期である保証はありません。

10-D　Pro版：Swing Curve近似・極値膜厚・山間／谷間の傾き

このカーブ評価と近似残差診断はPro版限定です。通常版はSHAP分布・依存図まで利用できます。APC学習画面にはPro版でもSwing Curve評価を表示しません。

レジスト膜厚のSHAP依存図を、c + m(t−t₀) + A sin(2π(t−t₀)/T + φ) で近似します。tは膜厚、Tは周期、Aは片振幅、mは直線トレンドです。表示するR²・RMSEはSHAP散布点への近似の評価であり、画面上部のGPRモデルの評価とは別です。

  1. 新規学習から進める場合は「2 Swing Curve学習」で下地モード・目的変数・説明変数を指定し、モデリング・SHAP評価を実行します。「④ 結果を比べて保存」の一覧で対象の行をクリックします。MAT保存は不要です。SHAPは先頭最大1000件で、GPR評価は全行です。
  2. 保存済みモデルなら「6 SHAP 解析」でMATと入力を開き、「SHAP依存確認」または「ノイズ除去用SHAP」を実行します。グラフ表示をオンにします。
  3. 結果の「グラフ」→「SHAP 依存: RESIST_TH」を開きます。学習画面では「グラフを大きく表示」を押すと広く表示できます。RESIST_THという説明変数名を持つモデルが対象です。
  4. 「膜厚下限・上限」で近似・プロットする範囲を指定します。読込データ内の範囲を指定し、異なる膜厚を8点以上含めます。
  5. 周期下限・上限を両方0にすると露光波長÷屈折率の75〜125%を探索します。初期値は248nm÷1.77です。周期が既知なら両方に正の値を入力して探索を絞ります。
  6. バルク効果の傾きを見る場合は「直線トレンドを含む」をオンにし、「近似を更新」を押します。設定変更時は古い近似・表を消します。

近似曲線はオレンジ、極大は紫、極小は青緑で表示します。極値の膜厚を点の近くへ表示し、同じ色の破線で隣接する山同士・谷同士を結びます。凡例のmが傾きです。表示範囲内の極値が24個を超える場合は文字の重なりを避け、膜厚の数値は表で確認します。

「近似方式」をスプライン補間に切り替えると、同じ膜厚のSHAP値を平均して通るnot-a-knotの3次補間になります。異なる膜厚は4点以上必要です。周期・一定振幅・一定傾きは定義せず、極値は補間曲線の微分から求め、山間・谷間の傾きは区間ごとに表示します。表示範囲は採用した補間点の端へ合わせ、外挿しません。近似残差は元の各観測行で計算します。補間点では残差がほぼ0となり、正規性検定は判定対象外になることがあります。膜厚の目盛・注記は指数表示を使いません。

内容が収まらない場合は、この依存図の内側を下へスクロールします。下の表は「近似指標」「極値の膜厚」「隣接する山・谷の傾き」を切り替えます。「極値の膜厚」は極大・極小ごとの膜厚とSHAP値、「隣接する山・谷の傾き」は両端の膜厚・SHAP値と差分の傾きです。目的の表を選び、結果の右下の「表を保存（CSV / Excel）」で出力します。グラフのPNGには近似曲線・極値・破線・凡例を含めます。

i

傾きと極値の読み方

三角関数近似は一定振幅の正弦波＋直線モデルなので、隣接する山間・谷間の傾きは同じ一定値mになります。スプライン補間では形状に応じて区間ごとの傾きが異なります。傾きはSHAP値の差÷膜厚の差で、単位は入力のままです。SHAP値や傾きだけで物理的なバルク効果を証明することはできません。

膜厚範囲を変更すると、その範囲の点だけで近似し直します。ズームだけでは近似対象・表を変更しないため、対象を変えるときは膜厚欄を変更して更新してください。曲線が単調で極値を持たない場合は極値なし、同種の極値が2個なければ隣接傾きなしと表示します。定数・直線だけのデータでは周期を表示しません。近似が弱い場合や周期が探索範囲の端にある場合は、説明文を確認して範囲を見直します。

10-E　Pro版：近似残差の正規性・歪度・尖度を確認する

ここでの残差はSHAP値−Swing Curve近似値です。GPRのモデル評価にある実測値−予測値の残差とは別です。近似に使った膜厚範囲の全観測行を使い、同じ膜厚の繰返しも各1行として診断します。

  1. 10-Dの手順で「近似を更新」します。
  2. 近似カーブの横の「残差分布」を選びます。ヒストグラムと、残差の平均・標準偏差から描いた正規分布の曲線を比較します。縦軸は件数ではなく確率密度です。
  3. 図の上にあるLilliefors検定の判定、p値、有意水準α=0.05、歪度・尖度・超過尖度を確認します。
  4. 「正規Q–Q」へ切り替え、点が斜めの基準線から曲がっていないか、両端が大きくずれていないか確認します。
  5. 「残差対膜厚」で、0の線を中心に残差が散らばるか、周期性や膜厚によるばらつきの変化が残っていないか確認します。
  6. 依存図の内側を下へスクロールし、「残差の正規性」または「残差データ」を選んで「表を保存（CSV / Excel）」を押します。CSV / Excelへ出力できます。各図は「グラフをPNG保存」の一覧から選びます。

11-C　実験計画作成

  1. 「7 実験計画作成」の①で方式（D最適・I最適・直交表、Pro版では拡張も）、評価するモデル、因子数、水準数（2〜5）、実験数を決めます。直交表は必要な実験数を自動で決めます。
  2. （Pro版のみ）既存の実験に追加する場合は「拡張 D最適」「拡張 I最適」を選び、②で既存の計画（−1〜1に符号化した値）のファイルを開いて、因子ごとに列を選びます。通常版には拡張の選択肢と②の欄がありません。
  3. 実験計画を作成 を押します。右に計画の表と、交絡の確認結果を表示します。
i

最適計画の限界

値は −1〜1 の符号化値です。D最適・I最適は局所探索のため、最良の計画である保証はありません。図の対角線以外が1に近い項どうしは、効果を区別できません。乱数seedは「9 設定」で指定し、同じseedなら同じ計画を再現できます。

11-D　ワードクラウド

「8 ワードクラウド」で文章を入力するか .txt を開き、ワードクラウドを作成 を押します。日本語は自動で単語に分けないため、単語の間を空白で区切ってください。1文字の単語は除きます。

11-E　設定とHelp

「9 設定」で、保存先、テーマ、文字の大きさ、カーネルの初期値、Fit method（すべての GPR に共通）、KL / MI ビン数、実験計画の因子数・実験数・seed、炉内補間の RBF 幅・正則化 を変更し、設定を保存して適用 を押します。太字の項目はこの画面だけで変更します。テーマと文字の大きさは保存するとすぐ反映し、それ以外は次の実行から反映します。表示中の結果や学習済みモデルの一覧は消えません。

文字の大きさは8〜20ポイントの整数（標準12）です。部品ごとに作成時の大きさを覚えておき、すべての画面の文字を同じ比率で拡大・縮小します（見出し・グラフの文字も含む）。大きくしすぎると、高さが決まった欄で文字が切れる場合があります。

「10 Help」には、用語の説明、操作のまとめ、MathWorks 公式の関数ヘルプ、手順書への入口があります。内容は版ごとに異なります。通常版では、Pro版だけの機能（swingperiodic・周期の探索範囲・カーブ近似と残差診断・拡張実験計画）の用語・操作・関数のリンクと、この手順書を開くボタンを表示しません（利用者向け手順書のボタンだけ）。Pro版ではすべてを表示します。ウィンドウの大きさは自由に変えられ、最大化もできます。

TROUBLESHOOTING

困ったとき

R2025b が必要、というメッセージで止まる

現在の MATLAB / Runtime が対象外です。作成 PC は version('-release') で確認し、R2025b を使います。配布先は Runtime R2025b と対応する exe の組合せを確認します。製品コードのリリース確認を外さないでください。

目的変数や説明変数を選ぶ場所が分からない

学習画面の上のタブ「② 変数を選ぶ」を開きます。左が目的変数、右が説明変数です。先に「① データを開く」でファイルを開くと選べるようになります。

MATLAB Compiler / Statistics Toolbox が見つからない

作成用 MATLAB の ver で製品のインストールを確認し、利用可能なライセンスも担当者に確認します。Runtime はビルド用 MATLAB の代わりにはなりません。

入力列を選んでいない、または必須列が不足と表示される

入力列の未選択・重複を見直し、必要な列をすべて割り当てます。列の中身は実行時に自動で確認されます。

ヘッダーが空 / 重複、または列名が合わない

元ファイルの指定ヘッダー行を確認します。説明文の行や空行をヘッダーとして指定していないか確認し、列名を一意にします。大小文字や余分な空白も確認します。

欠損値を含む行番号が表示される

表示された元ファイルの行を確認します。アプリはその行を削除して学習を継続しません。勝手な0埋めや平均値補完をせず、入力の扱いを確認して修正したファイルを再読込します。

データが少ないため処理を中止します

APC は25行未満で停止します。25行以上の有効データを用意します。25〜149行では注意警告が残ります。Swing Curveに APC の件数ルールを当てはめないでください。

SHAPが出ない

④の一覧の「SHAP」と「備考」を確認します。「未計算」「失敗」の行は、選んでから「選択モデルのSHAPを計算」を押します。MAT保存はSHAPの前提ではありません。

このモデルを制御に使用しないでください、と表示される

その MAT を制御へ渡さず、「保存後検証」タブの表の失敗行を確認します。元のモデルとファイルを保持し、モデルを作成した環境・設定とともに担当者へ確認します。

学習済みモデル（Train_Model）が見つかりません

別用途の MAT、または変数名が異なるファイルです。このアプリの仕様で作成されたモデルを選びます。別名の変数をアプリ側で勝手に読み替えません。

SHAP の処理が長い / 算出に失敗する

処理中表示と、停止時の詳細メッセージを確認します。モデルの説明変数順・入力形式・R2025b / Statistics Toolbox を確認します。計算時間の保証値はありません。測定値や機密データを外部サービスへ渡して対処しないでください。

相関や r² が NaN になる

2点未満、または片方の列がすべて同じ値など、相関を定義できない条件を確認します。NaN を良好なモデルの意味で扱わないでください。

RMSEやR²が表示されない

推定・SHAPでは評価用の実測列を選択してください。2件未満、実測が一定、実測0などで未定義になる指標はNaNと理由を表示します。

画面が狭くて見づらい

ウィンドウを広げるか最大化します。学習画面の④では「グラフを大きく表示」で一覧をたたみ、グラフを広く表示できます。

結果やログの保存に失敗する

保存先フォルダの書込み権限、ファイルが Excel 等で開かれていないか、空き容量を確認します。別の書込み可能なフォルダへ保存する場合も、社内の管理場所のルールに従います。

インストールしたアプリが起動しない

インストーラーが最後まで終わったか（MATLAB Runtime を含む）を確認し、PC を再起動してから試します。インストーラーを使わず exe を配った場合は、R2025b の MATLAB Runtime（ビルドと同じかそれ以降の更新版）が入っているか確認します。

手順書の画像が見えない

docs/user-guide フォルダ全体を移しているか確認します。images / base.css / procedure-guide.css / procedure-guide.js / guide-extra.css / guide-extra.js を HTML と同じ相対位置に置きます。

解決しない場合は、実行日時、利用したタブ、MATLAB / Runtime のリリース・更新版、表示されたエラー文、保存後検証の失敗項目を担当者へ伝えてください。エラーのスクリーンショットへ測定値や機密のファイル名が写る場合は、送付先と範囲を確認してください。
