BUILDER · INITIAL SETUP

App Designer の入口を作る

この章は作成担当者向けです。画面の配置・操作は作成済みの AnalysisController.m が担当します。App Designer では、その画面を呼び出す入口だけを用意します。

4-1ソースの画面を確認する

MATLAB コマンドウィンドウ
setup_paths;
controller = launch_analysis_app;

R2025b では10個のタブがある画面が開く想定です。R2025b 以外ではリリースエラーとなります。エラーを避けるために製品コードの確認処理を外さないでください。

確認：画面が開き、左のタブと右側の結果表が表示されること。

4-2空のアプリを作る

MATLAB コマンドウィンドウ
appdesigner
  1. App Designer が開いたら Blank App / 空のアプリ を選びます。
  2. UIFigure にはボタンや表を手動で置きません。
  3. Code View / コードビュー に切り替えます。

4-3Controller プロパティを追加する

Code View のツールバーで Property を選び、private のプロパティを追加します。既定の名前を Controller に変更します。すでに private の properties ブロックがある場合は、その中へ Controller の1行を追加します。

アプリ内の private プロパティ
properties (Access = private)
    Controller
end

App Designer が自動生成した UIFigure の定義やコンストラクターは削除しません。

確認：コードブラウザーのプロパティ一覧に Controller があること。

4-4startupFcn を追加する

  1. Component Browser の一番上のアプリ名を右クリックします。
  2. Callbacks → Add StartupFcn callback を選びます。Code View の Callback ボタンから、コンポーネントをアプリ自身、コールバックを StartupFcn として追加してもかまいません。
  3. 生成された function startupFcn(app) の本文に、下の4行を貼り付けます。
startupFcn の本文だけを貼り付ける
project_root = fileparts(fileparts(mfilename('fullpath')));
addpath(fullfile(project_root, 'core'), fullfile(project_root, 'app'));
require_r2025b();
app.Controller = AnalysisController(app.UIFigure);

関数宣言と最後の end は App Designer が生成します。上のコードを新しい別ファイルへ保存する必要はありません。

確認：起動時に AnalysisController(app.UIFigure) を呼ぶこと。

4-5AnalysisApp.mlapp として保存・実行する

  1. Save / 名前を付けて保存を選びます。
  2. 保存先をプロジェクトの app フォルダにします。
  3. ファイル名を AnalysisApp.mlapp として保存します。
  4. App Designer の Run を押します。
  5. 一度閉じてから appdesigner('app/AnalysisApp.mlapp') で開き直せることも確認します。

確認：10個の機能タブが表示されること。Design View には入口の空の UIFigure が表示され、実行時に画面が組み立てられます。

07

USER · COMMON OPERATION

入力ファイルと列の割当

学習・推定・SHAP・指標・要約統計量では、最初に入力データを読み込みます。ファイルの列順と、モデルへ渡す説明変数の順番は別です。必ず対応表を確認してください。

7-1CSV / Excel を選び、シートとヘッダー行を指定する

  1. 使う機能のタブを選び、Excel / CSV を開く を押します。
  2. .xlsx または .csv を選択します。
  3. Excel ではシート一覧から対象シートを選びます。CSV ではシート選択はありません。
  4. 「ヘッダーの行番号」に列名が書かれている行番号を入力します。先頭行なら 1 です。

確認：選択したファイル名、ヘッダー行、データ件数が左側に表示されること。

SIN_THSIN_RNNSG_THRESIST_THCD
100.11.9160.290550.3
99.81.9060.489850.1

上の数値は列構成を説明するための例で、製造条件の推奨値ではありません。この2行だけでは APC の学習はできません。

7-2入力プレビューを確認する

右側の 入力プレビュー タブを開き、ヘッダーと先頭のデータを見ます。画面に表示するのは先頭100行までです。実際の計算には読み込んだ全行を使用します。

確認：シートの取り違え、ヘッダー行のずれ、文字列の混入がないこと。

7-3列名からモデルの変数へ割り当てる

  1. 左の対応表の 入力列 を選びます。
  2. APC / スイングカーブは SIN_TH、SIN_RN、NSG_TH、RESIST_TH の順です。目的変数の行 y には、例では CD を選びます。
  3. 必須変数名と列名が完全一致すれば自動割当されます。一致しない列は手動で割り当てます。
  4. 上表の列対応・順序を確認 を押します。

確認：「列対応・順序を確認済みです。実行できます。」が表示されること。

!

確認をやり直すタイミング

入力ファイル、列割当、入力数、推定 / SHAP の方式、モデルを変更すると確認が解除されます。実行前に再度確認します。目的変数と説明変数に同じ入力列を割り当てることはできません。

入力の状態アプリの扱い
同名ヘッダーが重複 / ヘッダーが空読込時に停止します。Excel が自動改名した列として扱いません。
選択列に空セル / NaN学習・推定・SHAP・指標では停止し、元ファイルの行番号を表示します。
要約統計量の NaN8番タブだけは NaN を除外し、欠損件数も集計します。
Inf / 数値以外の文字列停止します。単位変換や文字列の自動置換で補いません。
08

USER · TRAINING

4種類のモデルを学習・保存する

タブ対応表の説明変数目的変数特有の動作
1 APC 学習SIN_TH → SIN_RN → NSG_TH → RESIST_THy25行未満は停止。25〜149行は警告。保存・検証後に SHAP。
2 スイングカーブ学習SIN_TH → SIN_RN → NSG_TH → RESIST_THyAPC の25行下限・150行警告は追加しません。
3 面内学習・推定X → Y。半径は内部で追加。y推定用データは省略可能。半径150 mm以上も除外しません。
4 汎用 GPR 学習指定した個数の入力1 → 入力2 → …y対応表の順番で数値行列を作り、列名は付けません。

8-1学習条件を設定する

7章に従ってデータと対応表を確認します。kernel と fit_method をドロップダウンで選択します。初回の確認では既定値 squaredexponential / exact を使用できます。BasisFunction は変更欄を設けず、正本どおりの設定を使います。

設定選択肢
kernelsquaredexponential / matern32 / matern52 / exponential / rationalquadratic / ardmatern52 / ardsquaredexponential
fit_methodexact / sd / sr / fic

学習に使う値を事前に標準化したり、単位変換したりしないでください。モデル内の Standardize=true が標準化を担当します。

8-2実行して MAT の保存先を選ぶ

  1. APC でグラフが必要なら グラフを表示（IsPlot = 1） にチェックします。
  2. 実行 を押します。
  3. 警告が出た場合は内容を読みます。件数不足などで停止した場合は、入力を見直してから再実行します。
  4. 学習後に保存ダイアログが開いたら、保存先とファイル名を指定します。例：apc_model_20261028.mat。

確認：保存を確定すると、自動で再読込して検証します。キャンセルした場合は保存せず、後続の SHAP / 面内推定も実行しません。

8-3保存後の検証を確認する

右下の 保存後の自動検証 を見て、各行の Passed がすべて成功であることを確認します。1つでも失敗したモデルは制御へ渡しません。APC の SHAP や面内の推定結果が上側に表示された後も、検証表は右下に残ります。

確認：変数名は Train_Model だけ、クラスは RegressionGP、説明変数順・ResponseName・学習条件・行数・保存前後の予測値が一致すること。

8-A　スイングカーブ学習

2 スイングカーブ学習 を選びます。RESIST_TH は必ず4番目の説明変数として割り当て、y を指定します。保存・検証までで処理が終わり、学習後 SHAP は自動では実行しません。ノイズ除去用 SHAP は10章から別に実行します。

8-B　面内学習と、追加の推定

  1. 3 面内学習・推定 を選び、学習用の X・Y・y を割り当てます。
  2. 学習と同時に別座標を推定するなら、推定用 Excel / CSV を開く（省略可） を押します。
  3. 推定用ファイルについても、シート・ヘッダー行を指定し、下の対応表で X・Y を割り当てます。
  4. 両方の対応表を確認してから実行します。保存・検証の成功後に推定を行います。

半径は学習・推定の両方へ追加されます。範囲外の行は OutsideTrainingRange で分かります。範囲チェックは X・Y・半径それぞれの最小〜最大であり、範囲内の予測精度を保証するものではありません。

8-C　汎用 GPR 学習

  1. 4 汎用 GPR 学習 を選びます。
  2. 数値欄で説明変数の個数を指定します。目的変数の y は個数に含めません。
  3. 入力1、入力2…の順に列を選び、最後の y に目的変数を割り当てます。
  4. 列の意味と順序を記録し、確認ボタンを押してから学習します。

このモデルではファイル上の名前をモデルの PredictorNames に設定しません。後で推定するときも、利用者が同じ入力順を選ぶ必要があります。

09

USER · PREDICTION

保存済みモデルで推定する

9-1モデルと推定方式を選ぶ

  1. 5 保存モデルで推定 を選びます。
  2. 方式欄で APC / スイング / 汎用は 汎用推定、面内モデルは 面内推定 を選びます。
  3. 学習済み MAT を開く を押し、利用するモデルを選びます。
  4. 表示された PredictorNames と ResponseName を確認します。

確認：列名を持たないモデルを、列数だけで面内モデルだと判断しないこと。利用するモデル種別を利用者が確認します。

9-2推定データを読み込み、説明変数順を合わせる

CSV / Excel を読み込み、対応表で入力列を選びます。汎用推定はモデルの PredictorNames の順に合わせます。面内推定に渡す入力は X・Y の2列です。半径は内部で追加されます。

入力ファイルに目的変数の列があっても、推定用の入力列には割り当てません。モデルの列数と異なる入力では停止します。

9-3確認して推定する

確認ボタンを押してから 実行 を押します。結果表の y_pred が予測値、SourceRow が元ファイルの行番号です。面内推定では OutsideTrainingRange=true の行を確認します。

確認：予測を出力するとき、元データの順序と SourceRow の対応が分かること。

10

USER · SHAP

SHAP 解析とノイズ除去用の寄与

10-A　APC 学習後の SHAP

APC では MAT の保存と自動検証が成功すると SHAP を算出します。対象は先頭から最大1000行です。ランダムに対象行を選びません。1000行を超えると制限の警告が残ります。IsPlot をオンにすると分布図と説明変数ごとの依存図を表示します。

10-B　別データで SHAP の依存関係を確認する

  1. 6 SHAP 解析 を選び、方式を SHAP依存確認 にします。
  2. 学習済み MAT と、解析したい CSV / Excel を選びます。
  3. モデルの PredictorNames と同じ順に入力列を割り当て、確認ボタンを押します。
  4. グラフが必要なら IsPlot をオンにして実行します。

画面の処理中表示が消えるまで待ちます。SHAP 結果は行が対象データ、列が説明変数です。SourceRow は元ファイルの行番号です。

10-C　スイングカーブのノイズ除去用 SHAP

  1. 方式を ノイズ除去用SHAP に変更します。
  2. スイングカーブ仕様の4変数モデルを選びます。
  3. SIN_TH、SIN_RN、NSG_TH、RESIST_TH を順に割り当てて再確認します。
  4. 実行し、結果の shap_resist を保存します。

shap_resist は RESIST_TH の寄与です。測定値そのものや、ノイズ除去済みの測定値ではありません。ノイズ除去用では、背景データ数を変える引数を付けない原仕様を維持しています。

i

グラフと処理件数

グラフは別ウィンドウです。重要度順に表示し、依存図の色は自分以外の重要な変数を使います。APC 学習後の1000行制限は対象行数の制限です。背景データは正本どおりモデル内の学習データを使うため、処理が短時間で終わる保証はありません。

USER · OTHER FUNCTIONS

指標・要約統計・DOE・ワードクラウド

11-A　評価指標

  1. 7 評価指標 でデータを読み込みます。
  2. col1 に実測値、col2 に予測値を割り当てます。
  3. 指標を選択し、KL / 相互情報量なら必要に応じてビン数を設定します。0 は自動です。
  4. 列の対応を確認し、実行します。
表示意味 / 条件
一括rmse → mae → r → r_squared の順。RMSPE / KL / 相互情報量は含みません。
RMSE / MAE値が小さいほど差が小さい指標です。元の値と同じ単位です。
RMSPE (%)百分率。col1 に0があると計算を停止します。
Pearson r相関係数。2点以上必要です。
r²（相関係数の2乗）1 − SSres / SStot とは異なります。一定量ずれた予測でも1になる場合があります。
KL / 相互情報量ヒストグラムと擬似カウントから計算。単位はそれぞれ nats / bits。ビン数に依存します。

11-B　列の要約統計量

8 列の要約統計量 で入力ファイルを開き、一覧から対象列を複数選びます。Windows で複数項目を選ぶときは Ctrl / Shift を使います。確認ボタンを押して実行すると、列ごとに横並びで表示します。

件数、欠損件数、平均、中央値、最大、最小、範囲、IQR、Q1、Q3、不偏標準偏差の11行です。NaN は除外します。有効な値が2件未満なら停止します。

11-C　D 最適計画

  1. 9 D 最適計画 を選びます。ファイル入力や列確認は不要です。
  2. 因子数と実験数を正の整数で入力します。例：因子数2、実験数12。
  3. 再現したい場合は seed を固定します。例：42。空欄なら毎回初期化します。
  4. 実行し、計画行列を CSV / Excel へ保存します。

作成するのは二次モデル用の符号化された計画値です。実際の温度や膜厚へ自動で換算しません。同じ seed の再現性を、同じ MATLAB 環境で確認してください。

11-D　ワードクラウド

  1. 10 ワードクラウド を選びます。
  2. テキスト欄へ直接入力するか、テキストファイルを開く から .txt を読みます。
  3. 日本語は単語間を空白で区切ります。自動の分かち書きはありません。
  4. 実行すると単語の件数表と、別ウィンドウの図が表示されます。

空白・全角空白・句読点・改行等で分割し、小文字化して集計します。1文字以下の単語は除外します。該当語が残らなければ入力を見直します。

TROUBLESHOOTING

困ったとき

R2025b が必要、というメッセージで止まる

現在の MATLAB / Runtime が対象外です。作成 PC は version('-release') で確認し、R2025b を使います。配布先は Runtime R2025b と対応する exe の組合せを確認します。製品コードのリリース確認を外さないでください。

build_windows:missingMlapp で止まる

app/AnalysisApp.mlapp がありません。4章の手順で作成し、保存先とファイル名を確認します。別名やプロジェクト直下への保存ではビルド入口に見つかりません。

MATLAB Compiler / Statistics Toolbox が見つからない

作成用 MATLAB の ver で製品のインストールを確認し、利用可能なライセンスも担当者に確認します。Runtime はビルド用 MATLAB の代わりにはなりません。

列対応が未確認、または必須列が不足と表示される

入力列の未選択・重複を見直し、必要な列をすべて割り当てます。その後「上表の列対応・順序を確認」を押します。入力やモデルを変えた後は再確認が必要です。

ヘッダーが空 / 重複、または列名が合わない

元ファイルの指定ヘッダー行を確認します。説明文の行や空行をヘッダーとして指定していないか確認し、列名を一意にします。大小文字や余分な空白も確認します。

欠損値を含む行番号が表示される

表示された元ファイルの行を確認します。アプリはその行を削除して学習を継続しません。勝手な0埋めや平均値補完をせず、入力の扱いを確認して修正したファイルを再読込します。

データが少ないため処理を中止します

APC は25行未満で停止します。25行以上の有効データを用意します。25〜149行では注意警告が残ります。スイングカーブに APC の件数ルールを当てはめないでください。

モデルを保存したのに SHAP / 面内推定が出ない

保存ダイアログをキャンセルしていないか、保存後検証が失敗していないかを確認します。保存キャンセル時は後続処理をしない仕様です。

このモデルを制御に使用しないでください、と表示される

その MAT を制御へ渡さず、右下の検証表の失敗行を確認します。元のモデルとファイルを保持し、モデルを作成した環境・設定とともに担当者へ確認します。

学習済みモデル（Train_Model）が見つかりません

別用途の MAT、または変数名が異なるファイルです。このアプリの仕様で作成されたモデルを選びます。別名の変数をアプリ側で勝手に読み替えません。

SHAP の処理が長い / 算出に失敗する

処理中表示と、停止時の詳細メッセージを確認します。モデルの説明変数順・入力形式・R2025b / Statistics Toolbox を確認します。計算時間の保証値はありません。測定値や機密データを外部サービスへ渡して対処しないでください。

相関や r² が NaN になる

2点未満、または片方の列がすべて同じ値など、相関を定義できない条件を確認します。NaN を良好なモデルの意味で扱わないでください。

ワードクラウドの表が出た後、title の入力引数エラーが出る

R2022b の参考撮影では title にフォント指定を渡す形式が非対応でした。図の撮影用コードでは Title プロパティを使用しています。アプリ本体の R2025b で同じエラーが出る場合は、AnalysisController.m の wordcloud / title 呼出しを保守担当者へ確認します。この手順書作成ではアプリ本体を変更していません。

結果やログの保存に失敗する

保存先フォルダの書込み権限、ファイルが Excel 等で開かれていないか、空き容量を確認します。別の書込み可能なフォルダへ保存する場合も、社内の管理場所のルールに従います。

exe が起動しない / DLL が見つからない

ビルドと同じ R2025b の Runtime、OS・64bit、対応する更新版を確認します。exe だけをコピーしていないか、付随ファイルと出力 readme も確認します。

手順書の画像が見えない

docs/user-guide フォルダ全体を移しているか確認します。images / base.css / procedure-guide.css / procedure-guide.js / guide-extra.css / guide-extra.js を HTML と同じ相対位置に置きます。

解決しない場合は、実行日時、利用したタブ、MATLAB / Runtime のリリース・更新版、表示されたエラー文、保存後検証の失敗項目を担当者へ伝えてください。エラーのスクリーンショットへ測定値や機密のファイル名が写る場合は、送付先と範囲を確認してください。
