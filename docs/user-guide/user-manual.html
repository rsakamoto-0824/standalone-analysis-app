Process Insight Tool
利用手順書（配布版・Windows）

データを開いてから、モデルの作成・比較・保存、推定と SHAP、結果の書出しまで。

対象：配布版（通常版）の利用者環境：Windows 11 / MATLAB Runtime R2025b更新：2026-11-26
01

START HERE

目的と対象

この手順書は、Windows の PC で Process Insight Tool（配布版・通常版）を使ってデータを解析する方向けです。モデルの作成・比較・保存、推定、SHAP解析、炉内補間、実験計画、結果の書出しを、画面の順に説明します。

左の目次から必要な章へ移動できます。画像はクリックすると拡大します。

メニューできること
1 APC 学習露光APC用のガウス過程回帰（GPR）モデルを学習し、制御用のMATファイルを保存します。説明変数は SIN_TH・SIN_RN・NSG_TH・RESIST_TH の4つです。
2 Swing Curve学習レジスト膜厚に対する線幅の周期的な変動（Swing Curve）を学習します。膜厚だけ、または下地の説明変数も使えます。
3 汎用回帰学習任意の列で、GPR・重回帰・PLS回帰・ランダムフォレスト・バギング木を学習して比べます。Permutation Importance と VIP（PLS）で、どの説明変数が効いているかも確かめられます。
4 炉内補間LP-CVD の BoatSlot ごとの膜厚・屈折率を、計測済みの Slot から補間します。成膜Run（バッチ）ごとに分けて計算します。
5 保存モデルで推定・SHAP保存したモデル、または学習した直後のモデルで、新しいデータの値を推定し、実測と比べます。どのモデルでも、各説明変数の効き方（SHAP値の分布と依存図）を同時に確かめられます。
6 実験計画作成D最適・I最適・直交表の実験計画を作り、D効率・I基準などの評価指標と、項どうしの重なり（交絡）を確認します。
i

画像について

画面の画像は、配布版（通常版）の画面を合成サンプルで操作して書き出した参考画像です。アプリの画面部分だけを写しており、Windows のウィンドウの枠（題名の行と右上の最小化・最大化・閉じるボタン）は含めていません。画面の中の配置やボタンは Windows でも同じですが、文字の形や大きさは PC の設定によって少し異なります。

02

HOW IT WORKS

全体の流れと画面の見方

1データを開く→2変数を選ぶ→3条件を決めて実行→4結果を比べて保存

モデルを作る画面（1〜4）は、上のタブがこの順番に左から並んでいます。学習と評価を先に行い、条件を比べてから、採用する1つのモデルだけを最後に保存します。

画面の場所役割
左のメニュー機能を切り替えます。「モデルを作る」「モデルを使う・調べる」「計画・その他」「アプリ」に分かれています。
上のタブ（①〜④）モデルを作る画面の手順です。左から順に進みます。
下の状況欄処理の状況と注意を、時刻つきで新しい順に表示します。エラーや注意はダイアログでも表示します。
進捗バー時間のかかる処理（モデリング・炉内補間）では、進んだ割合と残り時間の目安を表示します（5章）。
03

STEP 1

データを開く（① データを開く）

3-1ファイルを開く

  1. Excel / CSV を開く を押して、ファイルを選びます。
  2. Excel で複数のシートがある場合は、シート で選びます。
  3. 列名が1行目でない場合は、ヘッダー行 に列名の行の番号を入れます。変えるとすぐに読み直します。
  4. 下の表に先頭100行が表示されます。列名と値が正しく読めているかを確認します。

確認：ファイル名の横に「行数 × 列数」が表示され、表に列名とデータが見えること。

3-2グラフでデータの傾向を見る

左の欄は 横軸・縦軸・色・色の扱い の4つです。

  1. 表の上の グラフで傾向を見る タブを開きます。
  2. 縦軸 に見たい数値の列を選びます。
  3. 横軸 で レコード（行の順番） か、任意の列を選びます。文字の列を選ぶと、値ごとに並べて表示します。
  4. 色 で、点を色分けする列を選びます（色分けしない場合は (単色)）。ロットや装置名のような文字の列（質的変数）はグループごとの色と凡例、数値の列は連続した色になります。数値の列をグループとして色分けしたいときは 色の扱い で 質的（グループごとの色） を選びます。
  5. グラフを描く（追加） を押します。

右の 縦軸の要約 の表に、全体と色のグループごとの件数・平均・標準偏差などを表示します。描いたグラフと表には番号（1. 2. …）が付き、縦軸や色を変えて描き直しても、前のグラフは残ります（タブで見比べられます）。消すときは 結果を消す を押します（別のデータを開いたときも消えます）。左の欄が入りきらないときは、左の列ごと上下にスクロールできます。グラフと表は右下のボタンで保存・コピーできます。ここで見るだけで、学習に使うデータや列の選択は変わりません。

確認：縦軸の列の点が、横軸の順に並び、色の列で色分けされること。

i

別のファイルを開き直したとき

入力ファイルを開き直しても、すでに表示している結果や、学習済みモデルの一覧は消えません。同じ名前の列の選択は残ります。列の中身は、③ で実行したときに自動で確認します。

04

STEP 2

変数を選ぶ（② 変数を選ぶ）

4-1目的変数を選ぶ

左の 目的変数 で、予測したい列を選びます。複数の列を選ぶと、列ごとに別のモデルを作ります（最大20列）。複数選ぶときは Ctrl キーを押しながらクリックします。目的変数は、列名が CD・y・膜厚・屈折率のときだけ最初から選ばれています。それ以外は自分で選んでください。

4-2説明変数を選ぶ

画面選び方
1 APC 学習SIN_TH・SIN_RN・NSG_TH・RESIST_TH の4つそれぞれに、入力ファイルの列をドロップダウンで選びます。列名が同じなら自動で選ばれます。
2 Swing Curve学習モード で「下地なし（膜厚のみ）」か「下地あり」を選びます。レジスト膜厚の列 を選び、下地ありのときは 下地の説明変数 を一覧から選びます（複数可）。膜厚は必ず最後の説明変数（RESIST_TH）になります。
3 汎用回帰学習入力に使う列を一覧から選びます。順序を変えるときは、下の表で行をクリックしてから ▲ 上へ / ▼ 下へ を押します。

4-3選んだ内容を確かめる

右下の「モデルへ渡す順序」の表で、変数の名前と順序を確かめます。確認のボタンはありません。実行したときに、アプリが自動で列の中身を確認します。数値でない値・空欄・同じ列の重複・目的変数と説明変数の重なりがあると、理由を表示して止まり、この画面に戻ります。

確認：左下に緑の文字で「選択中：目的変数 ○列 / 説明変数 ○列」と表示されること。

05

STEP 3

条件を決めて実行する（③ 条件を決めて実行）

5-1モデルの条件を選ぶ

  1. GPRのカーネル を選びます。複数選ぶと、条件を比べます（Ctrl キーを押しながらクリック）。
  2. 汎用回帰では 回帰方式（GPR・重回帰・PLS回帰・ランダムフォレスト・バギング木）も選べます。PLS回帰を選ぶと PLSの成分数 を、ランダムフォレストかバギング木を選ぶと 木の本数（10〜1000、初期値100）を入力できます。
  3. GPR の Fit method は「7 設定」の値をすべての GPR に共通で使います。この画面では変えません。

5-2評価の方法を選ぶ

  • 初期状態（交差検証を使わない）：学習に使ったデータでの当てはまり（RMSE・R²）で評価します。条件をいくつ選んでも、この方法で比べられます。早く終わります。
  • 交差検証で評価する にチェックを入れると、データを分けて、学習に使っていない行での予測で評価します（分割数の初期値は5）。未知のデータに近い精度で比べられますが、学習の回数が「分割数＋1」倍になります。
  • SHAPも計算する を外すと、SHAP を省いて早く終わります。SHAP は後から ④ で計算できます。

学習に使ったデータでの当てはまりは、複雑なモデルほど良く見えます。採用を決める前に、交差検証や、学習に使っていないデータ（「5 保存モデルで推定・SHAP」（9章））でも確かめることをおすすめします。

5-3実行して、進捗バーで進み具合を見る

  1. 下の緑の文で、学習するモデルの数（目的変数 × 条件）と評価の方法を確認します。
  2. モデリング・SHAP評価を実行 を押します。すぐに進捗バーが表示されます。
  3. 進捗バーには、進んだ割合、経過時間、残り時間の目安、いま計算している目的変数と条件、処理の段階（交差検証の何分割目か、SHAP など）を表示します。
  4. 途中でやめるときは キャンセル を押します。今回の結果は一覧へ追加せず、以前の結果は残ります。

残り時間は、それまでの速さが続くと仮定した目安です。始まった直後は表示しません。

確認：進捗バーが100%になって閉じ、④ の一覧に結果が追加されること。

5-4　Swing Curve学習の条件

Swing Curve学習では、APC・汎用回帰と同じ GPR のカーネルから選びます。評価の方法は、ほかの学習画面と同じです。

06

STEP 4

結果を比べる（④ 結果を比べて保存）

6-1モデルの一覧から選ぶ

上の一覧に、学習したモデルが1行ずつ並びます。行をクリックすると、その下に評価とグラフを表示します。「順位」は同じ実行・同じ目的変数の中の RMSE の小さい順です。一覧は目的変数ごとにまとめ、その中を実行の順、同じ実行の中を順位の順に並べます（学習に失敗したモデルは各まとまりの最後）。目的変数が複数あっても、目的変数ごとに精度の良いモデルが上に来ます。「評価データ」が「学習データ」の行は、学習に使ったデータでの当てはまりで、未知のデータでの精度ではありません。条件を変えて ③ をもう一度実行しても、以前の結果は一覧に残ります。

グラフを広く見たいときは グラフを大きく表示 を押すと、一覧をたたみます。

6-2実測値と予測値・残差を見比べる

グラフ の 実測値と予測値・残差 のタブに、2つの散布図を横に並べて表示します。左は実測値と予測値（点線が y = x）、右は予測値と残差（実測 − 予測）です。色を指定する列 で、入力ファイルの任意の列により2つの図をまとめて色分けできます（ロットや装置など）。色を変えても評価の値は変わりません。

確認：2つの図が横に並び、色の列を変えると両方の色が変わること。

6-3SHAP依存図の色を、好きな説明変数に変える

  1. グラフ の SHAP 分布 で、各説明変数の効き方の広がりを見ます。
  2. SHAP 依存: 変数名 のタブで、その説明変数の値と SHAP値の関係を見ます。
  3. 上の 色の変数（説明変数） で、点の色に使う説明変数を選び直せます。最初は、その変数を除いて最も効いている説明変数が選ばれています。(単色) も選べます。

SHAP は予測への寄与を示す値で、因果関係を証明するものではありません。

確認：色の変数を変えると、点の色と右の色の目盛の名前が変わること。

6-4汎用回帰で、効いている説明変数を確かめる（変数重要度）

汎用回帰学習では、行を選ぶと Permutation Importance のグラフと 変数重要度 の表も表示します。1つの説明変数の値だけを行の間で並べ替えたとき、予測の誤差（RMSE）がどれだけ大きくなるかで、その変数がどれだけ予測に効いているかを表します（5回の平均とばらつき）。どの回帰方式でも使えます。

PLS回帰のモデルでは VIP（PLS） も表示します。VIP は1を超える変数が重要とされる目安です。

どちらも学習に使ったデータで計算します。互いに似た動きをする説明変数どうしでは、片方の重要度が小さく出ることがあります。

結果のタブ内容
グラフ実測値と予測値・残差、条件の比較（RMSE）、SHAP 分布・依存図。
評価指標R²・RMSE・RMSPE・MAE・相関・KLダイバージェンス・相互情報量の8指標。
予測・SHAPの出力（入力と並べた表）元データの説明変数・目的変数と、予測値・残差・SHAP値を並べた表（7章）。
検証分割交差検証のときの、分割ごとの行数と RMSE。
列の要約説明変数・実測・予測・残差の平均や四分位数など。
変数重要度（汎用回帰）説明変数ごとの Permutation Importance（RMSE の増加）と、PLS回帰では VIP。
保存後検証MAT保存後の自動検証の結果（7章）。

STEP 4 · SAVE

保存と書出し

7-1採用するモデルをMATファイルに保存する

  1. 一覧で保存するモデルの行をクリックします。
  2. 選択モデルをMAT保存 を押して、保存先を決めます。初期の名前は Train_Model_目的変数.mat（APC）、SwingCurve_Model_目的変数.mat、GenericGPR_Model_目的変数.mat、GenericRegression_Model_目的変数.mat（重回帰・PLS・ランダムフォレスト・バギング木）です。
  3. 保存後に自動で読み直して検証し、保存後検証 の表を表示します。

確認：保存後検証の Passed がすべてチェック済みであること。1つでも失敗すると「このモデルを制御に使用しないでください」と表示します。そのファイルは使わず、担当者に相談してください。

7-2予測値・残差・SHAP値を、元データと並べて1つのファイルに保存する

  1. 一覧で対象のモデルの行をクリックします。
  2. 予測・SHAPを1ファイルに保存 を押し、CSV か Excel を選んで保存します。

表示中の 予測・SHAPの出力（入力と並べた表） のタブで中身を確認できます。1行が元ファイルの1行に対応します。

列内容

目的変数の列入力ファイルの目的変数（実測値）。
目的変数_予測値モデルの予測値。交差検証のときは、その行を学習に使っていないモデルの予測（検証予測）です。
目的変数_残差実測値 − 予測値。
検証分割交差検証のとき、その行がどの分割で検証されたか。

確認：保存したファイルを Excel で開くと、列名の日本語が正しく表示されること。

7-3そのほかの表やグラフを書き出す

  • 表を保存（CSV / Excel）：表示中の表を保存します。
  • グラフをPNG保存：グラフを画像で保存します。横並びの散布図は、2つを並べた1枚の図、または片方だけを選べます。
  • グラフをコピー：グラフを画像としてクリップボードへ入れ、Excel や PowerPoint へ貼り付けられます。
  • 一覧を保存：④ のモデルの一覧を保存します。
i

CSV の文字コード

CSV は、Windows の Excel で日本語の列名が文字化けしないよう、文字コードの情報（BOM）を付けた UTF-8 で保存します。

08

FURNACE

炉内補間

「4 炉内補間」は、一部の BoatSlot だけにある計測値（膜厚・屈折率など）から、ほかの BoatSlot の値を補間します。学習の画面と同じ4ステップです。

  1. ① データを開く：WaferId・BoatSlot・計測値の列を持つファイルを開きます。異なる成膜Runのデータをまとめたファイルには、Runを区別するバッチの列を入れます。
  2. ② 列を選ぶ：WaferId・BoatSlot・バッチの列と、目的変数（補間したい計測値、複数可）を選びます。列の中身とバッチの区分は、実行したときに自動で確認します。
  3. ③ 条件を決めて実行：比べる方式と、予測する Slot の範囲・間隔を決めて実行します。進捗バーに、バッチの番号と進み具合を表示します。計測範囲の外は、チェックを入れたときだけ予測します（外挿）。
  4. ④ 結果を比べて保存：表示するモデル で Run・目的変数・方式を切り替えて曲線を比べ、選択モデルをMAT保存 で1つ保存できます。

内部Slot検証のRMSE のタブでは、目的変数ごとに棒グラフを分けて横に並べます（膜厚と屈折率のように単位の違う目的変数を、同じ軸に載せないため）。表示するのは選択中の Run で、選択中の方式の棒を濃い色にします。

!

検証の範囲

検証は、両端の計測 Slot を残して内部の Slot を1点ずつ外す方法です。端や外挿の精度は評価しません。各バッチ・各項目で5点以上の計測 Slot が必要です。保存したファイルは炉内補間専用の形式で、制御用のモデルとは別です。

09

USE A MODEL

保存モデルで推定・SHAP

「5 保存モデルで推定・SHAP」は、推定と SHAP 解析を1つにまとめた画面です。左の ①〜④ を上から進め、右に結果を表示します。どのモデル（APC・Swing Curve・汎用回帰・面内）でも、SHAP の分布と依存図を表示できます。

  1. ① モデルを選ぶ：学習済みMATを開く で読み込みます。この起動中に学習したモデルも、保存せずに 使用するモデル から選べます。信頼できる作成元の MAT だけを開いてください。
  2. ② データを開く：推定したいデータを開きます。
  3. ③ 列を割り当てる：モデルの説明変数ごとに入力ファイルの列を選びます。誤差も見たいときは 評価用の実測列（任意） を選びます。
  4. ④ 実行：④ 推定・SHAPを実行 を押します。

結果の 出力（入力・予測・SHAPを並べた表） に、元データの説明変数（割り当てた列）、実測列（選んだ場合）、予測値・残差、SHAP値（SHAP を計算したとき。先頭1000行より後は空欄）を1つの表で表示します。表を保存（CSV / Excel） で1つのファイルに保存できます。

③の SHAPも計算する（最初から選択）を選んだまま実行すると、推定と同時に SHAP（先頭最大1000行）を計算し、グラフ に SHAP 分布 と説明変数ごとの SHAP 依存: 変数名 を表示します。依存図の色の変数は 6-3 と同じように選び直せます。外すと推定だけを早く行います。

実測列を選んだ場合は、評価指標と、実測値と予測値・残差の横並びの散布図も表示します。評価に使うデータがモデルの学習に使っていないものかどうかは、利用者が確認してください。

OTHER FEATURES

実験計画・設定

実験計画作成

左の ① で方式（D最適・I最適・直交表）、評価するモデル、因子数、水準数（2〜5）、実験数を決め、実験計画を作成 を押します。値は −1〜1 の符号化値です。D最適・I最適は局所探索のため、最良の計画である保証はありません。乱数の seed は「7 設定」で変えます。

作成すると、右の 計画の評価指標 の表に、その計画の良さを表す指標を表示します（上の見出しにも主な値を表示します）。

指標読み方
D効率（%）係数をまとめて精度よく推定できるか。大きいほど良く、直交計画で100%です（D最適が重視する基準）。
A効率（%）係数の分散の合計の小ささ。大きいほど良い。
I基準（平均予測分散）−1〜1 の領域全体での予測のばらつきの平均（誤差分散を1とした値）。小さいほど良い（I最適が重視する基準）。
G効率（%）最も予測が悪い点の予測のばらつき。大きいほど良い。
最大VIF / 項どうしの最大相関項どうしの重なりの強さ。VIF は1に近いほど独立で、10を超えると重なり（多重共線性）が強い目安です。
残差の自由度実験数 − 項数。0だと誤差の大きさを推定できません。

グラフ の 予測分散の分布（FDS） は、領域のうち予測のばらつきがその値以下になる割合を表します。低く平らな線ほど、領域全体で予測が安定します。

設定

「7 設定」で、ファイルの保存先、テーマ、文字の大きさ、カーネルの初期値、Fit method、KL / 相互情報量のビン数、実験計画の seed、炉内補間の RBF の条件を変え、設定を保存して適用 を押します。表示中の結果や学習済みモデルの一覧は消えません。

  • 文字の大きさ：8〜20 ポイントの整数で指定します（標準は12）。保存するとすぐ、すべての画面の文字が同じ比率で変わります。見出しやグラフの文字も一緒に変わります。大きくしすぎると、欄に収まらない文字が出る場合があります。そのときは少し小さくしてください。
  • テーマも保存するとすぐ変わります。そのほかの項目は、次の実行から反映します。
