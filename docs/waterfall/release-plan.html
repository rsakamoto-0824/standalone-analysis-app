PIT-071.02026-11-23坂本確認・承認前

承認した配布物の生成、導入、互換確認と復旧を定める。

製品：Process Insight Tool。基準コミット：df9ffc2214c6196eefb389f890d25551d53f2b1d。文書の版と製品バージョンは別管理です。

準備と前提

本初版で配布は未承認です。ソースにはWindowsのexe・Runtime同梱インストーラーの生成処理がありますが、実生成と対象PCへの導入は未確認です。

対象準備
作成PCWindows 64bit、MATLAB R2025b、Statistics and Machine Learning Toolbox、MATLAB Compiler。
受入PCMATLAB本体のないWindows 64bit、対応するRuntime更新版。
配布物ProcessInsightTool.exeと付随ファイル、Runtime同梱インストーラー、manifest、サンプル、手順書。
管理情報コミット、製品バージョン、ビルド環境、SHA-256、試験結果、確認・承認記録。

ビルドと配布物

  1. 承認対象コミットを固定し、実データ・認証情報・意図しないファイルの混入を確認する。
  2. Windows R2025bで自動試験と本書のT-01〜19を実施し、実SHAPを含む対象要求の結果を保管する。
  3. build_windowsを実行する。既存.mlappがなければlaunch_analysis_app.mを入口とし、App Designerの手作業は不要。
  4. 出力・サンプル・手順書・manifestを確認し、配布物のSHA-256を記録する。
setup_paths;
result = build_windows;
出力先内容
build/windows/standard/application/ProcessInsightTool.exeと付随ファイル。
build/windows/standard/installer/Runtime同梱インストーラー。
build/windows/standard/edition-manifest.jsonビルド対象の構成・製品Version・Installer情報。

RuntimeDelivery=installerで同梱します。ビルドPCへ対応するRuntimeインストーラーを用意し、会社の承認済み手順で取得・持ち込みます。インストール時にネット接続を使わない配布を想定しますが、実環境での確認は未実施です。

実装根拠：build_windows.m

導入・移行

  1. 既存アプリ、MAT・入力・出力、設定・ログの保存先を確認し、書込み可能な別フォルダへバックアップする。
  2. 承認したハッシュのインストーラーを対象PCへ配布し、MATLAB本体なしで導入する。必要な権限・再起動は実環境で記録する。
  3. ネットなし導入、起動、1〜8のメニュー、サンプル、実SHAP、モデル保存・読込み、終了と再起動を確認する。
  4. 旧MATのコピーで新旧予測を比較し、実制御側の形式と許容差の合意前に原本を置き換えない。
  5. 係長が結果と残課題を確認し、課長が配布物・対象端末・残課題の扱いを承認して業務へ移行する。

復旧と配布中止

導入不能、保存検証失敗、旧モデルとの未合意な差等があれば配布を止めます。旧配布物とバックアップした設定へ戻し、入力と原本MATを保持します。新しいMATを旧環境へ無条件に渡しません。自動更新・自動復旧は提供せず、配布担当の手順で管理します。

本書の確認・承認は、コードのマージだけで代替しません。起動だけで移行完了にせず、実業務の精度・互換性も確認します。
