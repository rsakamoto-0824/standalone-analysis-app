確認・承認記録の保存方法

  1. 共有用ZIPは展開し、index.htmlをPCのEdge / Chromeで開きます。左の文書一覧から対象を開き、文書番号・文書版・基準コミットを確認します。全12文書を個別に確認・承認します。
  2. 各文書の末尾の「確認・承認記録」で、係長の氏名・レビュー日・判定・コメント、続いて課長の記録を入力します。日付だけでは判定は変わりません。
  3. 「記入済みHTMLを保存」で保存します。保存ファイルは元HTMLと同じフォルダに置き、開き直して記録を確認します。入力は自動保存されません。
  4. スタイル・JavaScript・imagesも一緒に保持します。「印刷／PDF保存」も使えます。記録欄は本人認証や電子署名を行う承認システムではありません。
  5. 変更時は文書版と改定履歴を更新し、影響する設計・試験・対応表を修正して、係長確認・課長承認を取り直します。
記入済みHTML・氏名・コメントは組織の管理先で保管してください。公開リポジトリへそのまま登録しません。

文書の再生成

ソースリポジトリ内で生成元_src/build_documents.mjsを実行します。記入済みファイルは先に別フォルダへ退避してください。生成元は相対パスで動作します。

node docs/waterfall/_src/build_documents.mjs

基準ファイルのSHA-256で参照ソースを特定できます。アプリのコード・動作は今回変更していません。
