回帰モデル

方式計算と保存の要点
GPRfitrgpの完全なRegressionGP。設定のFit method（exact / sd / sr / fic）を使用。カーネルは7種類の既存候補。
重回帰・PLS各学習行だけでX/yを標準化。切片付き最小二乗／plsregressで学習し、係数を元単位へ戻す。ランク不足と過大成分数を拒否。
ランダムフォレスト／バギング木回帰木のアンサンブル。初期100本、10〜1000本。方式に応じた説明変数抽出を使用。
変数重要度Permutation Importanceは入力の並べ替えでの誤差変化。PLS VIPは潜在成分への寄与。因果効果ではない。

実装根拠：core/train_modeling_candidate.m、core/ProcessRegressionModel.m、core/calc_permutation_importance.m

条件比較・検証・履歴

GPRはカーネルごと、他の回帰は方式ごとに候補を作り、目的変数×条件が100組以下かを検証します。Folds=0は学習データ評価、Folds≥2は共通分割による検証です。分割の学習行だけで前処理・学習し、未学習行の予測を全行結合して評価します。保存用には全行学習モデルを別に保持します。

条件が1つでもCVを選べます。順位は目的変数ごとに示します。Scope・単位・入力範囲の違う値は同じ採用判断に混ぜません。過去モデルと評価時の元入力をRecordに保持し、設定や入力の変更後も選択できます。履歴は終了で消えます。

実装根拠：core/modeling_conditions.m、core/evaluate_modeling_batch.m、core/evaluate_kernel_candidates.m、app/ModelStore.m

8評価指標・列の要約

指標定義と未定義条件
決定係数 R²1−Σ(y−ŷ)²/Σ(y−平均y)²。負値もある。実測一定なら未定義。
RMSE / MAEsqrt(平均((y−ŷ)²)) / 平均(|y−ŷ|)。応答と同じ単位。
RMSPE100×sqrt(平均(((y−ŷ)/y)²))。実測0があれば未定義。
Pearson r / 相関係数の2乗rとr²。決定係数とは異なり、予測の偏りを検出できない場合がある。
KLダイバージェンス共通等幅ビンの度数に1を加え規格化し、Σp log(p/q)。内部は自然対数。
相互情報量2次元ヒストグラムの度数に1を加え、H(X)+H(Y)−H(X,Y)。内部はlog2。

ビン数0は自動（10とceil(log2(N)+1)の大きい方）。0または2〜1000を設定画面で指定します。表示名へnats・bitsを付けません。計算不能はNaNとNoteで表示します。列要約は件数・平均・四分位・標準偏差等です。

実装根拠：core/evaluate_predictions.m、core/calc_kl_divergence.m、core/calc_mutual_information.m、core/calc_column_summary.m

SHAPと表示

モデルの学習データを背景としてSHAPを計算します。汎用クラスは予測関数をshapleyへ渡します。自動計算は先頭最大1000行です。分布は標準swarmchart、依存図は説明変数とSHAP値の関係を表示し、点の色の変数を変更できます。SHAPの計算失敗は学習失敗と分け、成功済みモデルを保持して再計算できるようにします。

予実と残差は同じタブに並べ、色は元行に対応する任意列で指定します。色の変更で学習・評価をやり直しません。

実装根拠：core/calc_shap_dependence.m、core/compute_shap_values.m、app/plot_shap_figures.m、app/EvaluationScatterView.m

炉内補間

Runと目的変数ごとに、利用可能な計測Slotで学習します。スプラインはnot-a-knot、poly3は3次最小二乗、RBFはGaussian基底＋直線。RBF幅0はSlot間隔中央値の2倍、正則化初期1e−8。GPRはsquaredexponential・matern52・rationalquadratic、共通Fit method、PredictMethod=exact、線形基底・標準化を使用します。

内部Slot検証では両端を学習に残し、内部点を1点ずつ外します。検証予測を結合して8指標を計算します。端部・外挿の精度まで検証したとは扱いません。外挿は初期オフで範囲外をNaNと理由にし、有効化したときに区別して表示します。GPRだけが95%応答予測区間を持ちます。

実装根拠：core/fit_furnace_model.m、core/evaluate_furnace_models.m、core/predict_furnace_model.m

実験計画

D/I計画は−1〜1の2〜5水準候補から座標交換する局所探索です。Iの積分領域は連続な一様領域です。同一水準の直交表を生成し、4水準には有限体GF(4)を使用します。D効率・A効率・I基準・G効率・VIF・予測分散と交絡を表示します。生成成功だけで全効果を識別できるとは扱いません。

実装根拠：core/create_experiment_design.m、core/design_metrics.m、core/design_diagnostics.m

例外処理

不正入力は実行前に元行・列と理由を示します。候補ごとの学習失敗とSHAP失敗を分け、中止時やエラー後も操作ロックを解除します。保存後検証の失敗したMATは使用しません。設定の読込み失敗は初期値と警告、ログの書込み失敗は通知で扱います。NaNの結果を0で補いません。
