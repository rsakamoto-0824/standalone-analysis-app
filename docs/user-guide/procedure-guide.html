BUILDER · INITIAL SETUP

App Designer の入口を作る

この章は作成担当者向けです。画面の配置・操作は作成済みの AnalysisController.m が担当します。App Designer では、その画面を呼び出す入口だけを用意します。

4-1ソースの画面を確認する

MATLAB コマンドウィンドウ
setup_paths;
controller = launch_analysis_app;

R2025b では9個のタブがある画面が開く想定です。R2025b 以外ではリリースエラーとなります。エラーを避けるために製品コードの確認処理を外さないでください。

確認：画面が開き、左のタブと右側の結果表が表示されること。

4-2空のアプリを作る

MATLAB コマンドウィンドウ
appdesigner
  1. App Designer が開いたら Blank App / 空のアプリ を選びます。
  2. UIFigure にはボタンや表を手動で置きません。
  3. Code View / コードビュー に切り替えます。

4-3Controller プロパティを追加する

Code View のツールバーで Property を選び、private のプロパティを追加します。既定の名前を Controller に変更します。すでに private の properties ブロックがある場合は、その中へ Controller の1行を追加します。

アプリ内の private プロパティ
properties (Access = private)
    Controller
end

App Designer が自動生成した UIFigure の定義やコンストラクターは削除しません。

確認：コードブラウザーのプロパティ一覧に Controller があること。

4-4startupFcn を追加する

  1. Component Browser の一番上のアプリ名を右クリックします。
  2. Callbacks → Add StartupFcn callback を選びます。Code View の Callback ボタンから、コンポーネントをアプリ自身、コールバックを StartupFcn として追加してもかまいません。
  3. 生成された function startupFcn(app) の本文に、下の4行を貼り付けます。
startupFcn の本文だけを貼り付ける
project_root = fileparts(fileparts(mfilename('fullpath')));
addpath(fullfile(project_root, 'core'), fullfile(project_root, 'app'));
require_r2025b();
app.Controller = AnalysisController(app.UIFigure);

関数宣言と最後の end は App Designer が生成します。上のコードを新しい別ファイルへ保存する必要はありません。

確認：起動時に AnalysisController(app.UIFigure) を呼ぶこと。

4-5AnalysisApp.mlapp として保存・実行する

  1. Save / 名前を付けて保存を選びます。
  2. 保存先をプロジェクトの app フォルダにします。
  3. ファイル名を AnalysisApp.mlapp として保存します。
  4. App Designer の Run を押します。
  5. 一度閉じてから appdesigner('app/AnalysisApp.mlapp') で開き直せることも確認します。

確認：9個の機能タブが表示されること。Design View には入口の空の UIFigure が表示され、実行時に画面が組み立てられます。

07

USER · COMMON OPERATION

入力ファイルと列の割当

学習・推定・SHAPでは、最初に入力データを読み込みます。ファイルの列順と、モデルへ渡す説明変数の順番は別です。必ず対応表を確認してください。

7-1CSV / Excel を選び、シートとヘッダー行を指定する

  1. 使う機能のタブを選び、Excel / CSV を開く を押します。
  2. .xlsx または .csv を選択します。
  3. Excel ではシート一覧から対象シートを選びます。CSV ではシート選択はありません。
  4. 「ヘッダーの行番号」に列名が書かれている行番号を入力します。先頭行なら 1 です。

確認：選択したファイル名とデータ件数が左側に表示されること。

SIN_THSIN_RNNSG_THRESIST_THCD
100.11.9160.290550.3
99.81.9060.489850.1

上の数値は列構成を説明するための例で、製造条件の推奨値ではありません。この2行だけでは APC の学習はできません。

7-2入力プレビューを確認する

右側の 入力プレビュー タブを開き、ヘッダーと先頭のデータを見ます。画面に表示するのは先頭100行までです。実際の計算には読み込んだ全行を使用します。

確認：シートの取り違え、ヘッダー行のずれ、文字列の混入がないこと。

7-3列名からモデルの変数へ割り当てる

  1. 左の対応表の 入力列 を選びます。
  2. APC / スイングカーブは SIN_TH、SIN_RN、NSG_TH、RESIST_TH の順です。目的変数の行 y には、例では CD を選びます。
  3. 必須変数名と列名が完全一致すれば自動割当されます。一致しない列は手動で割り当てます。
  4. 上表の列対応・順序を確認 を押します。

確認：「列対応・順序を確認済みです。実行できます。」が表示されること。

!

確認をやり直すタイミング

入力ファイル、列割当、入力数、推定 / SHAP の方式、モデルを変更すると確認が解除されます。実行前に再度確認します。目的変数と説明変数に同じ入力列を割り当てることはできません。

入力の状態アプリの扱い
同名ヘッダーが重複 / ヘッダーが空読込時に停止します。Excel が自動改名した列として扱いません。
選択列に空セル / NaN学習・推定・SHAP・指標では停止し、元ファイルの行番号を表示します。
Inf / 数値以外の文字列停止します。単位変換や文字列の自動置換で補いません。

USER · TRAINING

3種類のモデルを学習・評価・保存する

タブ説明変数の順序目的変数動作
1 APC 学習SIN_TH → SIN_RN → NSG_TH → RESIST_THy25行未満停止、25〜149行警告。保存・検証後にSHAP。
2 スイングカーブ学習SIN_TH → SIN_RN → NSG_TH → RESIST_THy学習・評価・保存・検証。SHAPは別のタブから実行。
3 汎用 GPR 学習入力1 → 入力2 → …y説明変数数を指定し、対応表の順に数値行列で学習。

面内学習機能は削除しました。既存の面内モデルを使った推定は「保存モデルで推定」で利用できます。

8-1学習条件と列対応を確認する

7章に従って入力を開き、説明変数とyを割り当てます。kernel と fit_method を選びます。初期値は squaredexponential / exact、BasisFunction は constant 固定です。設定を変更したら確認ボタンを押し直します。事前標準化や単位変換は行わず、モデル内の Standardize=true を使います。

8-2実行して画面上の評価を見る

  1. 必要なら「SHAP グラフをアプリ内に表示」をオンにします。
  2. 実行すると画面上部に RMSE、R²、件数を表示します。
  3. 右側の「モデル評価」で全8指標、「列の要約」で入力・実測・予測・残差の11項目を確認します。
  4. 「グラフ」で実測対予測・残差を確認します。

学習後に表示する指標は学習データへの当てはまりです。未知データでの性能や交差検証の結果ではありません。

8-3MATを保存して検証する

保存ダイアログでMATの保存先を指定します。初期フォルダは「設定」のデフォルト保存先です。「保存後検証」タブで Passed が全て成功していることを確認します。失敗したモデルは制御へ渡しません。

保存をキャンセルした場合も評価は画面に残りますが、MAT保存と後続SHAPは行いません。APCのSHAP値は別の「SHAP 値」タブに表示するため、実測・予測の結果表を保持できます。

USER · PREDICTION

保存済みモデルで推定・評価する

9-1モデルと推定方式を選ぶ

  1. 「4 保存モデルで推定」を選びます。
  2. APC / スイング / 汎用は「汎用推定」、既存の面内モデルは「面内推定（既存モデル）」を選びます。
  3. 学習済みMATを開き、PredictorNames / ResponseNameを確認します。
  4. 入力ファイルを開き、モデルと同じ説明変数の順番に割り当てます。

既存の面内モデルはX・Yの2列を割り当てます。半径は内部で追加します。列数だけでモデルの用途を自動判別しません。

9-2実測値列を任意で選ぶ

未使用データで評価したい場合、「評価用の実測列（任意）」で目的変数を選びます。説明変数と同じ列は選べません。実測値なしのままでも予測できますが、RMSE・R²は計算しません。入力・予測値の要約だけ表示します。評価・要約には2件以上必要です。

9-3列対応を確認して実行する

確認ボタンを押してから実行します。結果の SourceRow は元ファイルの行、y_pred は予測値です。既存の面内モデルの推定では OutsideTrainingRange で範囲外の行を確認します。実測を指定した場合は上部のRMSE・R²と評価表・要約・グラフも確認します。

10

USER · SHAP

SHAP解析とアプリ内のグラフ

10-A　APC学習後のSHAP

APCは保存・検証の成功後に先頭最大1000行でSHAPを計算します。評価指標は全学習行を使います。背景データは原仕様どおりモデル内の学習データです。処理時間の保証はありません。

10-B　保存済みモデルのSHAP

  1. 「5 SHAP 解析」で「SHAP依存確認」を選びます。
  2. MATと入力ファイルを開き、PredictorNamesと同じ順に列を割り当てます。
  3. 必要なら実測値列とKL/MIのビン数を指定します。
  4. 列対応を確認し、「SHAP グラフをアプリ内に表示」をオンにして実行します。
  5. 右側の「グラフ」を開き、その中で「SHAP 分布」「SHAP 依存: 変数名」を切り替えます。

分布図は平均|SHAP|の大きい順です。依存図は横軸が入力値、縦軸がSHAP値、色が自分以外の重要な変数です。外部のfigureウィンドウは作りません。

10-C　ノイズ除去用SHAP

方式を「ノイズ除去用SHAP」にして、SIN_TH、SIN_RN、NSG_TH、RESIST_THを割り当てます。結果の shap_resist はRESIST_THの寄与であり、測定値やノイズ除去済み測定値そのものではありません。背景データ数の引数を追加しない原仕様を維持します。

評価の読み方・実験計画・設定・Help

11-A　各モデル画面で評価・要約をまとめて確認

独立していた「7 評価指標」「8 列の要約統計量」のタブは削除しました。学習や実測値付きの推定・SHAPを実行すると、同じ画面の右側に自動で集計します。

指標意味・未定義となる条件
R²1−SSE/SST。1が完全一致、負値もあり。実測が一定なら未定義。
RMSE / MAE元の実測値と同じ単位。小さいほど差が小さい。
RMSPE (%)相対誤差。実測に0が含まれると未定義。
Pearson r / Correlation_squared相関とその2乗。R²と別の指標。一定の偏りを見逃す場合があります。
KL_nats / Mutual_information_bits実測分布から予測分布へのKLと、実測・予測のMI。ビン数に依存します。

未定義の指標はNaNと理由を表示し、他の指標は残します。要約は各列について件数・欠損数・平均・中央値・最大・最小・範囲・IQR・Q1・Q3・不偏標準偏差の11項目です。モデル入力に欠損があれば、従来どおり計算前に停止します。

11-B　実験計画作成

  1. 「6 実験計画作成」で方式を選びます。
  2. 因子数と評価モデルを指定します。linearは主効果、interactionは交互作用を含み、quadraticは平方項も含みます。
  3. D/Iでは実験数とseedを指定します。直交表は2/3水準を選び、必要な実験数を自動選択します。
  4. 実行後、表とランク、グラフ内の交絡図を確認します。
方式入力・意味
D最適モデル係数の推定情報量を重視。各因子−1/0/1の座標交換で局所探索。
I最適連続な一様領域[-1,1]^kの平均予測分散を重視。候補は−1/0/1、積分は厳密モーメントで計算。
直交表同一水準の2水準L4/L8/L16、3水準L9/L27。混合水準には非対応。実験数欄を使いません。
拡張 D最適 / 拡張 I最適既存計画を読込み、F1から因子列を割り当てて、追加数を指定。既存点の値・順序を保持します。

拡張の既存計画は因子ごとに下限−1、上限1へ事前に符号化してください。元の温度・膜厚等へ自動換算しません。既存＋追加がモデル項数未満なら停止します。対応範囲は1〜8因子、追加1〜300行、合計500行以下です。反復点を許します。

交絡図は二次モデル項の正規化内積の絶対値です。対角線以外の1は2項の完全交絡、0は直交、0ベクトル項は空白です。複数項の依存は「交絡の線形関係」表の各列を使い、係数で重みを付けた項の和が0になる関係として読みます。選択モデルのランクが項数より小さい場合、全係数を独立に推定できません。直交表でも二次モデルはランク不足になることがあります。

i

最適計画の限界

D/Iは4初期点・最大12巡の局所探索です。最適性を保証しません。選んだモデルと領域に依存するため、実験を開始する前に計画の妥当性を確認してください。計算方式は更新仕様を参照。

11-C　ワードクラウド

「7 ワードクラウド」で直接入力または.txtを読み込み、実行します。日本語は空白で区切ります。単語数は結果表、図はアプリ内の「グラフ」で確認します。1文字以下は除外し、小文字化して集計します。

11-D　ユーザー設定

  1. 「8 設定」を選びます。
  2. デフォルト保存先を入力またはフォルダ選択で指定します。
  3. ライト/ダーク、kernel、fit_method、説明変数数、ビン数、因子数、実験数、seed、SHAP図表示を編集します。
  4. 「設定を保存・適用」を押します。適用時は現在の結果を消し、列対応の確認を解除します。

次回起動にも設定を反映します。「初期値を画面に戻す」は編集欄だけを戻し、保存するまでファイルを変更しません。設定はprefdir配下のsettings.jsonに保存し、モデルMATに混ぜません。

11-E　Helpと画面サイズ

「9 Help」の用語表を選択すると説明全文を表示します。下のボタンでMathWorks公式の関数ヘルプや同梱の手順書を開けます。公式リンクだけネット接続を使用します。図はアプリ内に表示し、ヘルプリンクは既定ブラウザで開きます。

ウィンドウ幅1100px未満では入力が上、結果が下へ切り替わります。入力欄が収まらなければ入力部をスクロールします。横に広げると左右配置へ戻ります。

TROUBLESHOOTING

困ったとき

R2025b が必要、というメッセージで止まる

現在の MATLAB / Runtime が対象外です。作成 PC は version('-release') で確認し、R2025b を使います。配布先は Runtime R2025b と対応する exe の組合せを確認します。製品コードのリリース確認を外さないでください。

build_windows:missingMlapp で止まる

app/AnalysisApp.mlapp がありません。4章の手順で作成し、保存先とファイル名を確認します。別名やプロジェクト直下への保存ではビルド入口に見つかりません。

MATLAB Compiler / Statistics Toolbox が見つからない

作成用 MATLAB の ver で製品のインストールを確認し、利用可能なライセンスも担当者に確認します。Runtime はビルド用 MATLAB の代わりにはなりません。

列対応が未確認、または必須列が不足と表示される

入力列の未選択・重複を見直し、必要な列をすべて割り当てます。その後「上表の列対応・順序を確認」を押します。入力やモデルを変えた後は再確認が必要です。

ヘッダーが空 / 重複、または列名が合わない

元ファイルの指定ヘッダー行を確認します。説明文の行や空行をヘッダーとして指定していないか確認し、列名を一意にします。大小文字や余分な空白も確認します。

欠損値を含む行番号が表示される

表示された元ファイルの行を確認します。アプリはその行を削除して学習を継続しません。勝手な0埋めや平均値補完をせず、入力の扱いを確認して修正したファイルを再読込します。

データが少ないため処理を中止します

APC は25行未満で停止します。25行以上の有効データを用意します。25〜149行では注意警告が残ります。スイングカーブに APC の件数ルールを当てはめないでください。

モデルを保存したのに SHAPが出ない

保存ダイアログをキャンセルしていないか、保存後検証が失敗していないかを確認します。保存キャンセル時は後続処理をしない仕様です。

このモデルを制御に使用しないでください、と表示される

その MAT を制御へ渡さず、「保存後検証」タブの表の失敗行を確認します。元のモデルとファイルを保持し、モデルを作成した環境・設定とともに担当者へ確認します。

学習済みモデル（Train_Model）が見つかりません

別用途の MAT、または変数名が異なるファイルです。このアプリの仕様で作成されたモデルを選びます。別名の変数をアプリ側で勝手に読み替えません。

SHAP の処理が長い / 算出に失敗する

処理中表示と、停止時の詳細メッセージを確認します。モデルの説明変数順・入力形式・R2025b / Statistics Toolbox を確認します。計算時間の保証値はありません。測定値や機密データを外部サービスへ渡して対処しないでください。

相関や r² が NaN になる

2点未満、または片方の列がすべて同じ値など、相関を定義できない条件を確認します。NaN を良好なモデルの意味で扱わないでください。

RMSEやR²が表示されない

推定・SHAPでは評価用の実測列を選択してください。2件未満、実測が一定、実測0などで未定義になる指標はNaNと理由を表示します。

画面の入力欄が見切れる

入力部の内側をスクロールします。幅1100px未満では上下配置になります。横に広げると左右へ戻ります。

結果やログの保存に失敗する

保存先フォルダの書込み権限、ファイルが Excel 等で開かれていないか、空き容量を確認します。別の書込み可能なフォルダへ保存する場合も、社内の管理場所のルールに従います。

exe が起動しない / DLL が見つからない

ビルドと同じ R2025b の Runtime、OS・64bit、対応する更新版を確認します。exe だけをコピーしていないか、付随ファイルと出力 readme も確認します。

手順書の画像が見えない

docs/user-guide フォルダ全体を移しているか確認します。images / base.css / procedure-guide.css / procedure-guide.js / guide-extra.css / guide-extra.js を HTML と同じ相対位置に置きます。

解決しない場合は、実行日時、利用したタブ、MATLAB / Runtime のリリース・更新版、表示されたエラー文、保存後検証の失敗項目を担当者へ伝えてください。エラーのスクリーンショットへ測定値や機密のファイル名が写る場合は、送付先と範囲を確認してください。
