USER · COMMON OPERATION

画面の構成と、データの開き方

ここからは利用者向けです。どの機能も「左から右へ、上から下へ」進めば操作できるようにしています。

7-1ホームと左のメニューから機能を選ぶ

  1. 起動するとホームが開きます。やりたいことのボタン、または左のメニューから機能を選びます。
  2. 左のメニューは「モデルを作る（1〜4）」「モデルを使う・調べる（5 保存モデルで推定・SHAP）」「データを解析する（6 Sobol感度解析・7 因果探索・8 階層ベイズ・9 コピュラ乱数生成）」「計画・その他（10 実験計画作成・11 ワードクラウド）」「アプリ（12 設定・13 Help）」に分かれています（Pro版の番号）。Sobol感度解析・因果探索・階層ベイズ・コピュラ乱数生成・ワードクラウドは Pro 版だけで、通常版では「5 保存モデルで推定・SHAP」「6 実験計画作成」「7 設定」「8 Help」になります。
  3. 各画面の下にある状況欄に、処理の状況と注意を新しい順に表示します。エラーや注意はダイアログでも表示します。

7-2データを開く

  1. Excel / CSV を開く を押してファイルを選びます。
  2. Excel で複数のシートがある場合は、同じ画面の シート で選びます。
  3. 列名が1行目でない場合は ヘッダー行 の番号を変えます。変えるとすぐに読み直します。
  4. 下の表に先頭100行を表示します。列名と値が正しく読めていることを確認します。

手元にデータがない場合は サンプルデータを開く で、同梱の合成データを開けます。

確認：ファイル名の横に「行数 × 列数」が表示され、表に列名とデータが見えること。

7-3グラフでデータの傾向を見る（Pro版は9種類）

通常版は単変量の傾向だけで、左の欄は横軸・縦軸・色・色の扱いだけです（グラフの種類・列・群の分け方・群の数の欄はありません）。以下は Pro 版の操作です。

  1. 表の上の グラフで傾向を見る タブを開きます。
  2. グラフ の一覧で種類を選びます。Ctrl キーを押しながら複数選ぶと、一括で描けます。横軸・縦軸・色、または 列 の一覧で対象の列を選びます（選んだ種類のどれも使わない欄は灰色になります）。
  3. グラフを描く（追加） を押します。描いたグラフと表には番号（1. 2. …）が付き、種類を変えて描き直しても前の結果は残ります。消すときは 結果を消す を押します（別のデータを開いたときも消えます）。一括で描くとき、数値の列だけを使うグラフ（ヒストグラム・相関・Parallel Coordinates・PCA・クラスタリング）は、「列」の中の文字の列を除いて描きます。描けなかった種類は、理由をまとめて表示します。
  4. グラフと表は右下のボタンで保存・コピーできます。学習に使うデータや列の選択は変わりません。
グラフの種類使う欄内容
単変量の傾向（散布図）横軸・縦軸・色縦軸の数値の列を、レコード（行の順番）または任意の列に対して点で表示。色の列は文字（質的変数）ならグループごとの色と凡例、数値なら連続した色（「色の扱い」で切り替え）。通常版はこの1種類だけです。
ヒストグラム（Pro）列（最大12）・色列ごとの値の分布。色の列を選ぶとグループごとに重ねます。
相関マトリックス（Pro）列（2以上）Pearson の相関係数を色と数値で表示し、相関係数と p 値の表も出します。空欄は列の組ごとに除きます。
分散分析 ANOVA（Pro）縦軸（応答）・列（要因1〜4）主効果の分散分析（anovan）。ANOVA表（平方和・自由度・F値・p値・寄与率）、水準ごとの平均、要因ごとの箱ひげ図。数値の要因は6区間に分けます。
Parallel Coordinates（Pro）列（2以上）・色数値の列を縦軸として並べ、1行を1本の線で表示（各軸は最小〜最大にそろえ、軸の上下に最大・最小の値を表示）。
Parallel Sets（Pro）列（2〜6）・色列の値の組み合わせを帯で表示。帯の太さが行数。色は、選ばないとき最初の列の値。「色」で任意の列を選ぶと、文字の列・種類の少ない数値の列はグループごとの色、そのほかの数値の列は帯ごとの平均の連続した色（色の目盛りつき）。数値の列は6区間に分けます。
Sankey Diagram（Pro）列（2〜6）・色隣り合う列の間で値がどう移るかを流れで表示。色は、選ばないとき流れの元の水準。「色」で任意の列を選べます（Parallel Sets と同じ）。
主成分分析 PCA（Pro）列（2以上）・色標準化してから主成分分析。主成分得点の散布図、寄与率と累積寄与率、負荷量の図と表。
クラスタリング（Pro）列（2以上）・群の分け方・群の数標準化して k-means 法または Ward 法で群に分け、主成分得点で色分け表示。エルボー図、シルエット係数、Ward 法では樹形図も表示。k-means の初期値には設定の乱数seedを使います。
入力ファイルの条件内容
形式.xlsx または .csv。
列名（ヘッダー）空でない、重複しない名前にします。同じ列名を自動で変更しません。
値数値、または数値として読める文字。単位の変換や標準化は行いません。
空欄・NaN学習・推定・SHAP で選んだ列に空欄があると、元ファイルの行番号を表示して止まります（行を勝手に除いて続行しません）。炉内補間の計測列だけは「未計測」として扱います。
行番号結果の表の SourceRow は、元ファイルの行番号です。
i

列の確認は自動です

確認のボタンはありません。実行したときに、選んだ列の中身（数値でない値・空欄・重複・目的変数との重なり）をアプリが自動で確認し、問題があれば理由を表示して止まります。入力ファイルや選んだ列を変えても、表示中の結果や学習済みモデルの一覧は消えません。

USER · MODELING

学習：モデルを評価・比較して保存する

損失関数（分位点回帰）

③の 損失関数（GPR以外） で 分位点（ピンボール損失。分位点回帰） を選ぶと、GPR 以外のすべての方式が目的変数の 分位点 τ（0.01〜0.99、初期値0.9）を予測します（通常版でも重回帰・PLS・ランダムフォレスト・バギング木で使えます）。重回帰・PLS は重み付き最小二乗の繰り返し（IRLS）、ランダムフォレスト・バギング木は葉に入った学習データの目的変数の分布（Quantile Regression Forest）、ブースティング系は損失の勾配で木の形を選び、葉の値を残差の分位点にします。ハイパーパラメータの探索は、RMSE ではなくピンボール損失の小さい値を選びます（探索の表とグラフもピンボール損失で表示）。④の一覧の名前には「分位点τ=0.9」のように付き、実測が予測以下の割合（評価データで実測が予測以下だった行の割合。τ に近いほど良い）を表示します。木の方式は葉の最小行数が小さいと学習データに合わせすぎ、学習に使っていない行でこの割合が τ からずれやすいため、交差検証で評価し、ずれるときは葉の最小行数（XGBoost・LightGBM では20程度）を大きくするか、ブースティングの学習の回数を減らします（学習データでは τ どおりになるため、学習データでの評価では気づけません）。

質的変数と CatBoost の並べ替え列

②の 質的変数として扱う列 は、GPR だけでなくすべての回帰方式で使えます。重回帰・PLS は2番目以降の水準を表す0/1の列（ダミー変数）、ランダムフォレスト・バギング木は水準の組で分かれる木、EBM は水準ごとの効果、XGBoost・LightGBM は水準を勾配の比の順に並べて2つの組に分ける分岐、CatBoost は Ordered Target Statistics（並べた順で前の行だけの目的変数の平均）を使います。

CatBoost は行を並べ、各行の計算に「その行より前の行」だけを使います。③の CatBoost の並べ替え列 で日時・処理順などの列を選ぶと、その値の小さい順に並べます（文字の列は文字の順。日時を文字で入れる場合は「2024/01/05」のように桁をそろえます。説明変数に選んでいない列も選べます。指定しないときは乱数の順）。ハイパーパラメータの 順序付きブースティング（1=使う） を1にすると、各行の勾配を、並べた順で前の行だけで学習したモデルから求めます（Ordered Boosting。行数の2のべき乗ごとの補助モデルを使う、CatBoost と同じ近似）。交差検証では、各分割の学習に使う行の値だけで並べます。

8-8　Pro版の GPR：加法カーネルと質的変数

  • 加法カーネル：③の GPRのカーネル で additive を選びます。予測を「説明変数ごとの滑らかな効果の和」で表します（k = Σ_c σ_c² exp(−½((x_c−x_c')/ℓ_c)²)）。交互作用は表しませんが、変数が多くても当てはまりが崩れにくくなります。
  • 質的変数：②の 質的変数として扱う列 で、ロット・装置名などの列（文字の列も可）を選びます。同じ水準なら1、違う水準なら ρ（0〜1、列ごとに学習）を返すカーネルを、連続の列のカーネルに掛け合わせます（加法カーネルでは足し合わせます）。水準は値の名前の順に 1, 2, … と番号を付け、モデルに保存します。推定では学習時になかった水準を止めます。
  • 質的変数は GPR 以外の方式でも使えます（8-6）。加法以外のカーネルを選んだときは、連続の列に ARD 二乗指数を使います（名前は「GPR（ARD二乗指数×質的変数）」）。
  • カーネルのパラメータは周辺尤度の最大化で学習します（fitrgp の独自カーネル。Fit method は設定の値）。保存形式は Regression_Model です。出力の表の質的変数の列には水準の番号が入ります。

10-D　Pro版：Swing Curve近似・極値膜厚・山間／谷間の傾き

このカーブ評価と近似残差診断はPro版限定です。通常版はSHAP分布・依存図まで利用できます。APC学習画面にはPro版でもSwing Curve評価を表示しません。

レジスト膜厚のSHAP依存図を、c + m(t−t₀) + A sin(2π(t−t₀)/T + φ) で近似します。tは膜厚、Tは周期、Aは片振幅、mは直線トレンドです。表示するR²・RMSEはSHAP散布点への近似の評価であり、画面上部のGPRモデルの評価とは別です。

  2. 保存済みモデルなら「5 保存モデルで推定・SHAP」でMATと入力を開き、「汎用推定」（SHAPも計算する）または「ノイズ除去用SHAP」を実行します。
  3. 結果の「グラフ」→「SHAP 依存: RESIST_TH」を開きます。学習画面では「グラフを大きく表示」を押すと広く表示できます。RESIST_THという説明変数名を持つモデルが対象です。
  4. 「膜厚下限・上限」で近似・プロットする範囲を指定します。読込データ内の範囲を指定し、異なる膜厚を8点以上含めます。

近似曲線はオレンジ、極大は紫、極小は青緑で表示します。極値の膜厚を点の近くへ表示し、同じ色の破線で隣接する山同士・谷同士を結びます。凡例のmが傾きです。表示範囲内の極値が24個を超える場合は文字の重なりを避け、膜厚の数値は表で確認します。

内容が収まらない場合は、この依存図の内側を下へスクロールします。下の表は「近似指標」「極値の膜厚」「隣接する山・谷の傾き」を切り替えます。「極値の膜厚」は極大・極小ごとの膜厚とSHAP値、「隣接する山・谷の傾き」は両端の膜厚・SHAP値と差分の傾きです。目的の表を選び、結果の右下の「表を保存（CSV / Excel）」で出力します。グラフのPNGには近似曲線・極値・破線・凡例を含めます。

TROUBLESHOOTING

困ったとき

R2025b が必要、というメッセージで止まる

現在の MATLAB / Runtime が対象外です。作成 PC は version('-release') で確認し、R2025b を使います。配布先は Runtime R2025b と対応する exe の組合せを確認します。製品コードのリリース確認を外さないでください。

目的変数や説明変数を選ぶ場所が分からない

学習画面の上のタブ「② 変数を選ぶ」を開きます。左が目的変数、右が説明変数です。先に「① データを開く」でファイルを開くと選べるようになります。

MATLAB Compiler / Statistics Toolbox が見つからない

作成用 MATLAB の ver で製品のインストールを確認し、利用可能なライセンスも担当者に確認します。Runtime はビルド用 MATLAB の代わりにはなりません。

入力列を選んでいない、または必須列が不足と表示される

入力列の未選択・重複を見直し、必要な列をすべて割り当てます。列の中身は実行時に自動で確認されます。

ヘッダーが空 / 重複、または列名が合わない

元ファイルの指定ヘッダー行を確認します。説明文の行や空行をヘッダーとして指定していないか確認し、列名を一意にします。大小文字や余分な空白も確認します。

欠損値を含む行番号が表示される

表示された元ファイルの行を確認します。アプリはその行を削除して学習を継続しません。勝手な0埋めや平均値補完をせず、入力の扱いを確認して修正したファイルを再読込します。

データが少ないため処理を中止します

APC は25行未満で停止します。25行以上の有効データを用意します。25〜149行では注意警告が残ります。Swing Curveに APC の件数ルールを当てはめないでください。

SHAPが出ない

④の一覧の「SHAP」と「備考」を確認します。「未計算」「失敗」の行は、選んでから「選択モデルのSHAPを計算」を押します。MAT保存はSHAPの前提ではありません。

このモデルを制御に使用しないでください、と表示される

その MAT を制御へ渡さず、「保存後検証」タブの表の失敗行を確認します。元のモデルとファイルを保持し、モデルを作成した環境・設定とともに担当者へ確認します。

学習済みモデル（Train_Model）が見つかりません

別用途の MAT、または変数名が異なるファイルです。このアプリの仕様で作成されたモデルを選びます。別名の変数をアプリ側で勝手に読み替えません。

SHAP の処理が長い / 算出に失敗する

処理中表示と、停止時の詳細メッセージを確認します。モデルの説明変数順・入力形式・R2025b / Statistics Toolbox を確認します。計算時間の保証値はありません。測定値や機密データを外部サービスへ渡して対処しないでください。

相関や r² が NaN になる

2点未満、または片方の列がすべて同じ値など、相関を定義できない条件を確認します。NaN を良好なモデルの意味で扱わないでください。

RMSEやR²が表示されない

推定・SHAPでは評価用の実測列を選択してください。2件未満、実測が一定、実測0などで未定義になる指標はNaNと理由を表示します。

画面が狭くて見づらい

ウィンドウを広げるか最大化します。学習画面の④では「グラフを大きく表示」で一覧をたたみ、グラフを広く表示できます。

結果やログの保存に失敗する

保存先フォルダの書込み権限、ファイルが Excel 等で開かれていないか、空き容量を確認します。別の書込み可能なフォルダへ保存する場合も、社内の管理場所のルールに従います。

インストールしたアプリが起動しない

インストーラーが最後まで終わったか（MATLAB Runtime を含む）を確認し、PC を再起動してから試します。インストーラーを使わず exe を配った場合は、R2025b の MATLAB Runtime（ビルドと同じかそれ以降の更新版）が入っているか確認します。

手順書の画像が見えない

docs/user-guide フォルダ全体を移しているか確認します。images / base.css / procedure-guide.css / procedure-guide.js / guide-extra.css / guide-extra.js を HTML と同じ相対位置に置きます。

解決しない場合は、実行日時、利用したタブ、MATLAB / Runtime のリリース・更新版、表示されたエラー文、保存後検証の失敗項目を担当者へ伝えてください。エラーのスクリーンショットへ測定値や機密のファイル名が写る場合は、送付先と範囲を確認してください。

15-1　Sobol感度解析（6）

  1. ①で解析の対象を選びます。データ（Excel / CSV）から：ファイルを開き、出力（目的変数）の列と入力の列（数値）を選びます。保存モデルで：MAT、または起動中に学習したモデルを選びます。
  2. ②の表で、入力ごとの下限・上限を確認・編集します。初期値はデータ（保存モデルでは学習データ）の最小〜最大です。質的変数（Pro版で質的変数を使って学習したモデル）は全水準を同じ割合で使います。
  3. ③で、入力の分布（データから解析するとき。データの分布＝経験分布、または範囲内の一様分布）、代替モデル（GPR〈ARD〉またはランダムフォレスト200本）、基本の標本数 N（初期値1024）、ブートストラップ回数、分布図の範囲 平均 ± nσ の n を決め、④ Sobol感度解析を実行 を押します。予測の回数は N ×（入力の数＋2）です。

各入力を互いに独立に動かしたとき、出力の分散のうちその入力で説明できる割合を求めます。1次の指数 S1 = E[f_B (f_ABi − f_A)] / V（Saltelli 2010）、全効果の指数 ST = E[(f_A − f_ABi)²] / (2V)（Jansen）。標本はスクランブルした Sobol 列（乱数seedは設定の値）、予測値は平均を引いてから計算します。ひげはブートストラップの95%区間です。ST − S1 が大きい入力は交互作用が強く、S1 の合計が1に近いほど交互作用が小さいといえます。

  • データから解析するときは、代替モデルを全データで学習し、5分割の交差検証で当てはまり（R²・RMSE）を「代替モデルの当てはまり」の表に出します。交差検証の R² が0.5未満なら注意を表示します。経験分布では、入力をデータの値の分位点から取ります。
  • 表の S1_データから直接 は、モデルを使わずに求めた1次の指数です（入力を √行数（5〜30）個の区間に分け、区間ごとの出力の平均のばらつき ÷ 出力全体のばらつき。区間の数から見込まれる偏り (区間数−1)/(行数−1) を差し引く）。代替モデルの結果と大きく違うときは、代替モデルの当てはまりか、入力どうしの相関を疑います。
  • 「予測値の分布」のグラフと「予測値の分布の統計」の表に、平均・中央値・最頻値（カーネル密度推定の山の頂点）・95%区間（2.5〜97.5%点）・平均 ± kσ（k = 1〜n）と、その範囲に入る割合（正規分布なら入る割合と並べる）を出します。
  • 入力どうしの相関は考えません（独立に動かします）。

15-2　因果探索（7）

  1. ①でデータを開き、②で数値の列を2〜50列選びます。
  2. ③で方法を選びます。PC アルゴリズムは、偏相関の検定（Fisher の z、有意水準）で関係のない組の辺を外し（条件づける列は最大3列まで。変更可）、V字構造と Meek の規則で向きを決めます。向きの決まらない辺は破線で残します。DirectLiNGAM は、誤差が正規分布でないことを使って因果の順序を決め（最大エントロピー近似による尺度）、各列を順序が前の列へ回帰して、有意でない係数の辺を外します。
  3. ④の 前もって分かっている因果（任意） で、元・先の列と種類を選んで 追加 を押します。種類は → この向きはあり得ない（例：後の工程 → 前の工程。逆向きは残る）、― 因果はない（どちらの向きも）、→ この向きの因果がある（検定によらず残す）の3つです。矛盾する指定（ある と あり得ない、両向きの「ある」、「ある」の循環）は追加の時点で理由を表示します。②で選んでいない列を含む指定は使いません。PC は知識に反する向きを決めず、因果がある組は検定で外しません。DirectLiNGAM は因果の元を先に並べ、あり得ない向きを回帰に使いません。
  4. ⑤ 因果探索を実行 を押すと、因果グラフ（線の太さと数値は偏相関または標準化した係数）と辺の表（指定で残した辺は「事前の知識」に表示）、DirectLiNGAM では因果の順序を表示します。
!

因果探索の限界

どちらも線形の関係と、未観測の共通原因がないことを仮定します。PC は正規分布、DirectLiNGAM は非正規の誤差を仮定します。推定した向きは仮説で、因果関係の証明ではありません。実験や工程の知識で確かめてください。

15-3　階層ベイズ（8）

  1. ①でデータを開き、②で目的変数（数値）、グループの列（ロット・装置など。文字の列も可）、説明変数（数値、0列も可）を選びます。
  2. ③で、グループごとに推定する係数（切片と傾き、または切片だけ）、MCMC の繰り返し回数、最初に捨てる回数、鎖の数を決めます。
  3. ④ 階層ベイズを実行 を押します。

モデルは y = 切片_g + Σ 傾き_gk x_k + 誤差、グループごとの係数 ~ N(μ, Σ)。ギブスサンプリングで、目的変数・説明変数を標準化して計算し、元の単位へ戻します。事前分布は標準化した単位で μ・共通の係数 ~ N(0, 10²)、Σ ~ 逆ウィシャート（項数＋2、単位行列）、σ² ~ 逆ガンマ(1, 1)。結果は「全体の係数」「グループごとの係数」（グループ単独の最小二乗と並べる）「ばらつき」（残差とグループ間の標準偏差）「予測と残差」の表と、グループごとの係数の図、収束の確認（鎖ごとの σ のトレース）、実測値と予測値の図です。データの少ないグループほど係数が全体の平均へ引き寄せられます。R-hat が1.1以上の量があると注意を表示します。

15-4　コピュラ乱数生成（9）

  1. ①で作り方を選びます。データの関係をまねる：Excel / CSV を開き、関係をまねる数値の列（2〜20列）を選びます。関係を指定して作る：変数の数（2〜10）、変数ごとの名前・分布・パラメータ、変数どうしの順位相関（Spearman ρ または Kendall τ）を表に入れます（i 行 j 列を変えると j 行 i 列も同じ値になります）。
  2. ②でコピュラの種類（ガウス・t・Clayton・Frank・Gumbel）、周辺分布（データの関係をまねるとき）、生成する個数（10〜1,000,000）、乱数seedを決めます。
  3. ③ 乱数を生成 を押します。「生成した乱数」の表を選んで 表を保存（CSV / Excel） で保存します。
  • コピュラは、各列の分布とは別に、列どうしの順位の関係だけを表します。データの関係をまねるときは、各列を (順位)/(行数+1) に直した値に copulafit を当てはめます（t は近似の最尤法）。周辺分布は、経験分布（データの値の分位点。範囲の外の値は出ません）・カーネル密度・正規・対数正規・ワイブル・ガンマから選びます（対数正規・ワイブル・ガンマは正の値の列だけ）。
  • 関係を指定するときの分布とパラメータ：正規（平均, 標準偏差）、一様（下限, 上限）、対数正規（log の平均, log の標準偏差）、ワイブル（尺度 A, 形状 B）、ガンマ（形状 a, 尺度 b）、三角（下限, 最頻値, 上限）、指数（平均）、ベータ（a, b）。順位相関は copulaparam でコピュラのパラメータへ直します。t コピュラの自由度は5です。t・Clayton・Frank・Gumbel は Kendall τ で指定し、Clayton・Gumbel は正の関係だけを表せます。実現できない相関の組み合わせ（行列が正定値にならない）は理由を表示して止めます。
  • Clayton は小さい値どうし、Gumbel は大きい値どうしが同時に出やすい関係、t は両方の裾で同時に出やすい関係、ガウス・Frank は裾の同時の動きが弱い関係です。Clayton・Frank・Gumbel は2列だけで使えます。
  • 結果：「順位相関の比較」（元または指定と生成の Kendall τ・Spearman ρ。計算は先頭5000行）、「列の要約」、「コピュラのパラメータ」の表と、横軸・縦軸を選べる散布図（元のデータは灰、生成は青）、列ごとの分布（元と生成）の図です。
