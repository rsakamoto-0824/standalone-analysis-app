4-2空のアプリを作る

appdesigner
  1. App Designer が開いたら Blank App / 空のアプリ を選びます。
  2. UIFigure にはボタンや表を手動で置きません。
  3. Code View / コードビュー に切り替えます。

Code View のツールバーで Property を選び、private のプロパティを追加します。既定の名前を Controller に変更します。すでに private の properties ブロックがある場合は、その中へ Controller の1行を追加します。

end

App Designer が自動生成した UIFigure の定義やコンストラクターは削除しません。

確認：コードブラウザーのプロパティ一覧に Controller があること。

4-4startupFcn を追加する

  1. Component Browser の一番上のアプリ名を右クリックします。
  2. Callbacks → Add StartupFcn callback を選びます。Code View の Callback ボタンから、コンポーネントをアプリ自身、コールバックを StartupFcn として追加してもかまいません。
  3. 生成された function startupFcn(app) の本文に、下の4行を貼り付けます。
startupFcn の本文だけを貼り付ける

USER · COMMON OPERATION

入力ファイルと列の割当

左の1〜10の画面切替メニューは見出し全文を読める幅を確保しています。4番の炉内補間は、3番の汎用GPRの直下です。ウィンドウを狭くした場合もメニュー幅を保ち、入力と結果を上下に配置します。

学習・推定・SHAPでは、最初に入力データを読み込みます。ファイルの列順と、モデルへ渡す説明変数の順番は別です。必ず対応表を確認してください。

7-1CSV / Excel を選び、シートとヘッダー行を指定する

  1. 使う機能のタブを選び、Excel / CSV を開く を押します。
  2. .xlsx または .csv を選択します。
  3. Excel ではシート一覧から対象シートを選びます。CSV ではシート選択はありません。
  4. 「ヘッダーの行番号」に列名が書かれている行番号を入力します。先頭行なら 1 です。

確認：選択したファイル名とデータ件数が左側に表示されること。

SIN_THSIN_RNNSG_THRESIST_THCD
100.11.9160.290550.3
99.81.9060.489850.1

上の数値は列構成を説明するための例で、製造条件の推奨値ではありません。この2行だけでは APC の学習はできません。

7-2入力プレビューを確認する

右側の 入力プレビュー タブを開き、ヘッダーと先頭のデータを見ます。画面に表示するのは先頭100行までです。実際の計算には読み込んだ全行を使用します。

確認：シートの取り違え、ヘッダー行のずれ、文字列の混入がないこと。

7-3列名からモデルの変数へ割り当てる

  1. 左の対応表の 入力列 を選びます。
  2. APC / Swing Curveは SIN_TH、SIN_RN、NSG_TH、RESIST_TH の順です。目的変数の行 y には、例では CD を選びます。
  3. 必須変数名と列名が完全一致すれば自動割当されます。一致しない列は手動で割り当てます。
  4. 上表の列対応・順序を確認 を押します。

確認：「列対応・順序を確認済みです。実行できます。」が表示されること。

!

確認をやり直すタイミング

入力ファイル、列割当、入力数、推定 / SHAP の方式、モデルを変更すると確認が解除されます。実行前に再度確認します。目的変数と説明変数に同じ入力列を割り当てることはできません。

入力の状態アプリの扱い

Inf / 数値以外の文字列停止します。単位変換や文字列の自動置換で補いません。
08

USER · TRAINING

3種類のモデルを学習・評価・保存する

タブ説明変数の順序目的変数動作
1 APC 学習SIN_TH → SIN_RN → NSG_TH → RESIST_THy25行未満停止、25〜149行警告。保存・検証後にSHAP。
2 Swing Curve学習SIN_TH → SIN_RN → NSG_TH → RESIST_THy学習・評価・保存・検証。チェックすると学習後にSHAPとSwing Curve近似。
3 汎用 GPR 学習入力1 → 入力2 → …y説明変数数を指定し、対応表の順に数値行列で学習。

面内学習機能は削除しました。既存の面内モデルを使った推定は「保存モデルで推定」で利用できます。

8-1学習条件と列対応を確認する

7章に従って入力を開き、説明変数とyを割り当てます。kernel と fit_method を選びます。初期値は squaredexponential / exact、BasisFunction は constant 固定です。設定を変更したら確認ボタンを押し直します。事前標準化や単位変換は行わず、モデル内の Standardize=true を使います。

8-2実行して画面上の評価を見る

  1. 必要なら「SHAP グラフをアプリ内に表示」をオンにします。
  2. 実行すると画面上部に RMSE、R²、件数を表示します。
  3. 右側の「モデル評価」で全8指標、「列の要約」で入力・実測・予測・残差の11項目を確認します。
  4. 「グラフ」で実測対予測・残差を確認します。

学習後に表示する指標は学習データへの当てはまりです。未知データでの性能や交差検証の結果ではありません。

8-3MATを保存して検証する

保存ダイアログでMATの保存先を指定します。初期フォルダは「設定」のデフォルト保存先です。「保存後検証」タブで Passed が全て成功していることを確認します。失敗したモデルは制御へ渡しません。

保存をキャンセルした場合も評価は画面に残りますが、MAT保存と後続SHAPは行いません。APC / Swing Curve学習後のSHAP値は別の「SHAP 値」タブに表示するため、実測・予測の結果表を保持できます。

8-4　Swing Curve向けの周期カーネルを選ぶ

「2 Swing Curve学習」のkernelでswingperiodicを選べます。レジスト膜厚RESIST_THに周期性を持たせ、他3変数の影響と膜厚の線形トレンドも組み合わせます。APC・汎用GPRの候補は従来どおりです。

  1. 入力ファイルを開き、SIN_TH、SIN_RN、NSG_TH、RESIST_TH、yを割り当てます。異なる膜厚を8点以上含めます。
  2. kernelにswingperiodicを選び、fit_methodを選びます。まずは標準のexactを使えます。
  3. 列対応を確認して実行します。周期の入力は不要です。周期はKernelParametersやOptimizeHyperparametersに含めず、内部の1次元探索で計算します。
  4. 進捗に表示される候補ごとの学習を待ちます。各周期でGPRを再学習するため、通常の学習より時間がかかります。中止は進行中の候補の学習が終わり、次の候補へ移る前に反映されます。
  5. 終了後、左欄で採用した周期・尤度・探索範囲・評価回数を確認します。周期の単位はRESIST_THの入力単位です。
  6. MATを保存し、保存後検証で周期・カーネル量・予測の一致も確認します。保存モデルを開いたときにも周期を表示します。

右の「周期の最適化」は、Evaluation（評価順）、Period（周期）、LogLikelihood（周辺対数尤度）、Succeeded（学習の成否）、Message（失敗理由）の表です。exactでは周辺対数尤度、sd / sr / ficではそれぞれの近似周辺対数尤度を比較し、大きい値のモデルを採用します。表を選んで「表示中の表を保存」でCSV / Excelへ保存できます。

「グラフ」→「周期探索（周辺尤度）」で候補と採用点を確認し、必要ならPNGへ保存します。探索履歴は今回の画面と書出し表で保持し、MATには履歴変数を追加しません。MATの変数は従来どおりTrain_Modelだけで、周期はモデル内に保持します。

i

内部探索の範囲と読み方

周期範囲は、膜厚点間隔と全体の膜厚幅から自動設定します。最大48候補で、候補ごとに長さ尺度・振幅・ノイズなどを学習します。局所解、周期の取り違え、探索境界の影響があるため、大域最適性や物理的な周期の正しさは保証しません。警告と履歴を確認し、未知データへの予測精度も別に確認してください。

カーネルで選んだ周期と、10-DのSHAP散布点への正弦波近似の周期は、対象と基準が異なる別の結果です。同じ値になるとは限りません。毎回swingperiodicを使う場合は、11-Dの「設定」→「Swing Curve専用 kernel」で既定値を保存できます。計算方式は更新仕様に記載しています。R2025bでの実学習・モデル保存・SHAP、制御側での予測、Windows Runtimeの最終確認は未実施です。

8-5　複数カーネルを一括検証して採用モデルを選ぶ

  4. 検証の分割数（2〜10、既定5）と比較用seed（既定0）を設定します。左欄でfit_methodを確認します。KL / MIのビン数は「9 設定」で保存・適用した共通値を使います。
  5. 列対応を確認し、「選択したカーネルを一括比較」を押します。
  6. 候補・分割・全データ学習の進捗を確認して待ちます。中止は実行中の学習や周期候補の計算が終わった時点で反映されます。中止時はモデルを保存せず、比較結果を破棄します。

検証の仕組みと計算量

各候補で同じランダムな行分割を使います。各群を学習から外して予測し、全行の検証予測を結合して8指標を計算します。分割別指標の単純平均ではありません。周期カーネルの周期探索も各分割の学習データだけで行います。候補ごとに「分割数＋1」回を順に学習し、周期カーネルはさらに各学習内で最大48候補を探索するため、時間・メモリーが増えます。APCは各分割の学習に25行以上が必要です。

!

採用後に独立データで確認する

この比較はロット・時系列・同じ試料の反復などを分離せず、行をランダムに分割します。データに依存関係がある場合、そのまま未知データの精度と解釈できません。また、カーネル選定にも使った検証値には選定による偏りがあります。採用後は別の独立データで評価してください。

失敗候補は比較一覧に理由を表示し、順位と保存候補から外します。全候補が失敗した場合も理由を確認できます。入力・列対応・学習条件・ビン数・設定を変更すると比較結果を消去します。比較画面の候補・分割数・seedを変更した場合も比較をやり直してください。比較用のseedは通常の単独学習の乱数設定には影響しません。R2025bの実GPR比較・選択モデル保存とWindows / Runtimeでの動作確認は未実施です。公式の交差検証されたGPRの説明も参照できます。本アプリは原仕様の学習処理と周期探索を保つため、分割ごとに既存の学習関数を呼び出します。

USER · SHAP

SHAP解析とアプリ内のグラフ

10-A　APC学習後のSHAP

APCは保存・検証の成功後に先頭最大1000行でSHAPを計算します。評価指標は全学習行を使います。背景データは原仕様どおりモデル内の学習データです。処理時間の保証はありません。

10-B　保存済みモデルのSHAP

  1. 「6 SHAP 解析」で「SHAP依存確認」を選びます。
  2. MATと入力ファイルを開き、PredictorNamesと同じ順に列を割り当てます。
  3. 必要なら実測値列を指定します。KL/MIのビン数は「9 設定」の共通設定で変更します。
  4. 列対応を確認し、「SHAP グラフをアプリ内に表示」をオンにして実行します。
  5. 右側の「グラフ」を開き、その中で「SHAP 分布」「SHAP 依存: 変数名」を切り替えます。

分布図は平均|SHAP|の大きい順です。依存図は横軸が入力値、縦軸がSHAP値、色が自分以外の重要な変数です。外部のfigureウィンドウは作りません。

10-C　ノイズ除去用SHAP

方式を「ノイズ除去用SHAP」にして、SIN_TH、SIN_RN、NSG_TH、RESIST_THを割り当てます。結果の shap_resist はRESIST_THの寄与であり、測定値やノイズ除去済み測定値そのものではありません。背景データ数の引数を追加しない原仕様を維持します。

10-D　Swing Curve近似・極値膜厚・バルク効果の傾き

レジスト膜厚のSHAP依存図を、c + m(t−t₀) + A sin(2π(t−t₀)/T + φ) で近似します。tは膜厚、Tは周期、Aは片振幅、mは直線トレンドです。表示するR²・RMSEはSHAP散布点への近似の評価であり、画面上部のGPRモデルの評価とは別です。

  1. 新規学習から進める場合は「2 Swing Curve学習」で「学習後にSHAP・Swing Curve近似を計算」をオンにして実行し、MAT保存と検証を完了します。既定ではオフです。学習後のSHAP対象は先頭最大1000件で、GPR評価は全行です。
  2. 保存済みモデルなら「6 SHAP 解析」でMATと入力を開き、「SHAP依存確認」または「ノイズ除去用SHAP」を実行します。グラフ表示をオンにします。
  3. 右の「グラフ」→「SHAP 依存: RESIST_TH」を開きます。RESIST_THという説明変数名を持つモデルが対象です。
  4. 「膜厚下限・上限」で近似・プロットする範囲を指定します。読込データ内の範囲を指定し、異なる膜厚を8点以上含めます。
  5. 周期下限・上限を両方0にすると自動探索します。膜厚点の間隔と範囲から初期探索範囲を決めます。周期が既知なら両方に正の値を入力して探索を絞ります。
  6. バルク効果の傾きを見る場合は「直線トレンドを含む」をオンにし、「近似を更新」を押します。設定変更時は古い近似・表を消します。

近似曲線はオレンジ、極大は紫、極小は青緑で表示します。極値の膜厚を点の近くへ表示し、同じ色の破線で隣接する山同士・谷同士を結びます。凡例のmが傾きです。表示範囲内の極値が24個を超える場合は文字の重なりを避け、膜厚の数値は表で確認します。

内容が収まらない場合は、この依存図の内側を下へスクロールします。下の表は「近似指標」「極値の膜厚」「隣接する山・谷の傾き」を切り替えます。「極値の膜厚」は極大・極小ごとの膜厚とSHAP値、「隣接する山・谷の傾き」は両端の膜厚・SHAP値と差分の傾きです。目的の表を選び、画面下の「表示中の表を保存」でCSV / Excelへ出力します。グラフのPNGには近似曲線・極値・破線・凡例を含めます。

i

傾きと極値の読み方

一定振幅の正弦波＋直線モデルなので、隣接する山間・谷間の傾きは同じ一定値mになります。区間ごとに異なる傾きや振幅の変化を推定するモデルではありません。傾きはSHAP値の差÷膜厚の差で、単位は入力のままです。SHAP値や傾きだけで物理的なバルク効果を証明することはできません。

膜厚範囲を変更すると、その範囲の点だけで近似し直します。ズームだけでは近似対象・表を変更しないため、対象を変えるときは膜厚欄を変更して更新してください。曲線が単調で極値を持たない場合は極値なし、同種の極値が2個なければ隣接傾きなしと表示します。定数・直線だけのデータでは周期を表示しません。近似が弱い場合や周期が探索範囲の端にある場合は、説明文を確認して範囲を見直します。

10-E　近似残差の正規性・歪度・尖度を確認する

ここでの残差はSHAP値−Swing Curve近似値です。GPRのモデル評価にある実測値−予測値の残差とは別です。近似に使った膜厚範囲の全観測行を使い、同じ膜厚の繰返しも各1行として診断します。

  1. 10-Dの手順で「近似を更新」します。
  2. 近似カーブの横の「残差分布」を選びます。ヒストグラムと、残差の平均・標準偏差から描いた正規分布の曲線を比較します。縦軸は件数ではなく確率密度です。
  3. 図の上にあるLilliefors検定の判定、p値、有意水準α=0.05、歪度・尖度・超過尖度を確認します。
  4. 「正規Q–Q」へ切り替え、点が斜めの基準線から曲がっていないか、両端が大きくずれていないか確認します。
  5. 「残差対膜厚」で、0の線を中心に残差が散らばるか、周期性や膜厚によるばらつきの変化が残っていないか確認します。
  6. 依存図の内側を下へスクロールし、「残差の正規性」または「残差データ」を選んで「表示中の表を保存」を押します。CSV / Excelへ出力できます。各図は「グラフを PNG に保存」の一覧から選びます。

  2. デフォルト保存先を入力またはフォルダ選択で指定します。

  4. 「設定を保存・適用」を押します。適用時は現在の結果を消し、列対応の確認を解除します。

次回起動にも設定を反映します。「初期値を画面に戻す」は編集欄だけを戻し、保存するまでファイルを変更しません。設定はprefdir配下のsettings.jsonに保存し、モデルMATに混ぜません。旧設定にSwing Curve専用kernelがない場合は、以前のkernelを引き継ぎます。

KL / MIビン数は全画面で共通です。この設定画面だけで、0（自動）または2〜1000を指定します。「設定を保存・適用」後の単独学習、保存モデル推定、SHAP、カーネル比較、炉内補間に同じ値を使います。設定を変更すると古い評価結果は消去されるため、再実行してください。

11-F　LP-CVDの炉内補間：バッチ別にBoatSlotから予測する

「4 炉内補間」は、同じ成膜Runで同時に処理する複数Lotの膜厚・屈折率を、BoatSlotを説明変数として補間します。異なるRunの入力をまとめた場合は、バッチ列を選ぶとRunごとに別のモデルを学習します。バッチはカテゴリとして区分にだけ使い、数値の大小を学習させません。WaferIdも識別のために保持し、回帰の入力にはしません。

入力列指定・扱い
WaferId（必須）各Waferの識別子。1バッチ内で重複させません。CSVは先頭ゼロを保つ文字列として読みます。Excelでは識別子を文字列で入力してください。
BoatSlot（必須）正の整数の位置。同じバッチ内で重複できません。異なるバッチで同じSlotが出ることはできます。
膜厚・屈折率など（1列以上）目的変数として複数選択できます。空欄はその項目の未計測として除き、項目ごとに利用できる計測点で学習します。各バッチ・各項目に5点以上必要です。
バッチ（任意）成膜Runを一意に識別する値。列を選択した場合は空欄を認めません。バッチ列なしではファイル全体を1Runとして扱うため、複数Runを含む場合は必ず指定します。

WaferIdを対応付けたい未計測Waferは、WaferId・BoatSlot・バッチを入力し、計測列だけ空欄にします。入力にないSlotも範囲から生成できますが、WaferIdは自動で作らず空欄になります。以下は架空の2Runを含むCSVの例で、各項目に計測済みSlotが5点ずつあります。

  1. 「4 炉内補間」を開き、Excel / CSVのシートとヘッダー行を指定します。
  2. WaferId列、BoatSlot列、必要ならバッチ列を指定し、目的変数をCtrl / Commandで複数選択します。列名が一致すれば自動で割り当てますが、内容を確認してください。
  3. 比較する方式を選びます。既定では6方式を選択しています。スプライン・3次多項式・RBFだけ、またはGPRの複数カーネルだけでも実行できます。
  4. 予測Slotの下限・上限・間隔を指定します。読込直後の下限・上限は入力Slotの最小・最大です。実際のBoatの全範囲を自動推定するものではありません。
  5. 必要ならRBF幅・正則化を変更します。KL / MIのビン数は「9 設定」の共通設定を使います。外挿は初期状態で無効です。
  6. 「列・バッチ区分・予測範囲を確認」を押し、バッチ数・計測項目数と識別子の対応を確認します。
  7. 「バッチごとに比較・補間」を押します。バッチ・項目・方式・内部Slot検証の進捗を確認します。中止は実行中の1学習が終わった時点で反映され、今回の部分結果は表示・保存しません。
方式今回の設定
スプラインMATLABのsplineによるnot-a-knotの3次補間です。計測点を通りますが、点間での過大・過小な振れには注意してください。
3次多項式近似（poly3）y = a×BoatSlot³ + b×BoatSlot² + c×BoatSlot + d を、同じRun・同じ計測項目の全学習データへ最小二乗法で当てはめます。学習行だけでSlotと応答を規格化して計算し、元の単位へ戻します。計測点を必ず通るスプラインとは異なります。
RBFGaussian基底＋直線トレンドを正則化して回帰します。幅はBoatSlotの単位です。0では各学習内の計測Slot間隔の中央値の2倍を使い、手入力した幅は固定します。正則化の既定値は1e−8です。
GPRsquaredexponential・matern52・rationalquadratic。exact、線形基底、Standardize=trueで、各学習内で応答も規格化してカーネル量とノイズを学習し、予測値・区間を元の単位に戻します。追加のCurve Fitting / Deep Learning Toolboxは使いません。

検証は、両端の計測Slotを残して内部Slotを1点ずつ外し、その未使用位置を予測します。検証予測を結合して8指標を求めます。端の2点の検証予測はNaNで対象外理由を示します。全計測Slotで学習した指標とは別に表示し、順位は同じバッチ・同じ目的変数内でRMSE、同値ならMAE、さらに同値なら候補順で付けます。膜厚と屈折率、異なるRunの誤差を一つの順位に混ぜません。

  1. 上の選択欄で「バッチ / 目的変数 / 方式」を切り替えます。「グラフ」では、そのバッチ・項目の全成功候補のプロファイル、内部Slot検証のRMSE、選択候補の検証残差を確認できます。
  2. 「予測結果」は全バッチ・全項目・全成功候補を含みます。Batch、WaferId、SourceRow、Target、Method、BoatSlot、Actual、Predicted、ResponseSD、Lower95、Upper95、OutsideMeasuredRange、Regionを確認します。SourceRowがNaN・WaferIdが空欄なら入力にない生成Slotです。
  3. GPRを選ぶと応答の95%予測区間を図と表に表示します。スプライン/RBF/3次多項式の区間はNaNです。範囲外は通常「範囲外・未計算」とし、外挿を有効にした場合だけ表と破線で示します。
  4. 「モデル比較」「全評価指標」「検証予測」「選択モデル要約」も確認し、表示中の表をCSV / Excelへ、図をPNGへ保存します。炉内補間ではモデルMATを保存せず、再実行時は入力と条件から再計算します。
!

検証の限界と失敗時の確認

この検証は内部Slotの補間だけを評価し、両端・外挿の精度は評価しません。候補選定にも使った値なので、採用前に別の未使用計測値でも確認してください。同一バッチ内のWaferId / BoatSlotの重複、バッチや識別子の空欄、数値以外・Infは停止します。計測不足や学習失敗は対象バッチ・項目・方式のNoteへ理由を残し、他の対象を続けます。

入力は最大100バッチ、1バッチ300行、20計測項目、1〜1,000,000のSlot値、予測位置2,000点までです。一括出力は20万行、計画する学習は最大2万回までに制限し、超える場合は分割を案内します。各項目・各方式で「内部の計測Slot数＋1」回を学習するため時間がかかります。詳細は計算仕様、公式のpolyfit、spline、GPRの予測区間を参照してください。R2025bの実GPRとWindows / Runtimeでの一連の確認は未実施です。

TROUBLESHOOTING

困ったとき

R2025b が必要、というメッセージで止まる

現在の MATLAB / Runtime が対象外です。作成 PC は version('-release') で確認し、R2025b を使います。配布先は Runtime R2025b と対応する exe の組合せを確認します。製品コードのリリース確認を外さないでください。

build_windows:missingMlapp で止まる

app/AnalysisApp.mlapp がありません。4章の手順で作成し、保存先とファイル名を確認します。別名やプロジェクト直下への保存ではビルド入口に見つかりません。

MATLAB Compiler / Statistics Toolbox が見つからない

作成用 MATLAB の ver で製品のインストールを確認し、利用可能なライセンスも担当者に確認します。Runtime はビルド用 MATLAB の代わりにはなりません。

列対応が未確認、または必須列が不足と表示される

入力列の未選択・重複を見直し、必要な列をすべて割り当てます。その後「上表の列対応・順序を確認」を押します。入力やモデルを変えた後は再確認が必要です。

ヘッダーが空 / 重複、または列名が合わない

元ファイルの指定ヘッダー行を確認します。説明文の行や空行をヘッダーとして指定していないか確認し、列名を一意にします。大小文字や余分な空白も確認します。

欠損値を含む行番号が表示される

表示された元ファイルの行を確認します。アプリはその行を削除して学習を継続しません。勝手な0埋めや平均値補完をせず、入力の扱いを確認して修正したファイルを再読込します。

データが少ないため処理を中止します

APC は25行未満で停止します。25行以上の有効データを用意します。25〜149行では注意警告が残ります。Swing Curveに APC の件数ルールを当てはめないでください。

モデルを保存したのに SHAPが出ない

保存ダイアログをキャンセルしていないか、保存後検証が失敗していないかを確認します。保存キャンセル時は後続処理をしない仕様です。

このモデルを制御に使用しないでください、と表示される

その MAT を制御へ渡さず、「保存後検証」タブの表の失敗行を確認します。元のモデルとファイルを保持し、モデルを作成した環境・設定とともに担当者へ確認します。

学習済みモデル（Train_Model）が見つかりません

別用途の MAT、または変数名が異なるファイルです。このアプリの仕様で作成されたモデルを選びます。別名の変数をアプリ側で勝手に読み替えません。

SHAP の処理が長い / 算出に失敗する

処理中表示と、停止時の詳細メッセージを確認します。モデルの説明変数順・入力形式・R2025b / Statistics Toolbox を確認します。計算時間の保証値はありません。測定値や機密データを外部サービスへ渡して対処しないでください。

相関や r² が NaN になる

2点未満、または片方の列がすべて同じ値など、相関を定義できない条件を確認します。NaN を良好なモデルの意味で扱わないでください。

RMSEやR²が表示されない

推定・SHAPでは評価用の実測列を選択してください。2件未満、実測が一定、実測0などで未定義になる指標はNaNと理由を表示します。

画面の入力欄が見切れる

入力部の内側をスクロールします。幅1100px未満では上下配置になります。横に広げると左右へ戻ります。

結果やログの保存に失敗する

保存先フォルダの書込み権限、ファイルが Excel 等で開かれていないか、空き容量を確認します。別の書込み可能なフォルダへ保存する場合も、社内の管理場所のルールに従います。

exe が起動しない / DLL が見つからない

ビルドと同じ R2025b の Runtime、OS・64bit、対応する更新版を確認します。exe だけをコピーしていないか、付随ファイルと出力 readme も確認します。

手順書の画像が見えない

docs/user-guide フォルダ全体を移しているか確認します。images / base.css / procedure-guide.css / procedure-guide.js / guide-extra.css / guide-extra.js を HTML と同じ相対位置に置きます。

解決しない場合は、実行日時、利用したタブ、MATLAB / Runtime のリリース・更新版、表示されたエラー文、保存後検証の失敗項目を担当者へ伝えてください。エラーのスクリーンショットへ測定値や機密のファイル名が写る場合は、送付先と範囲を確認してください。
