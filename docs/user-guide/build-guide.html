BUILD GUIDE

Process Insight Tool
ビルド手順書（通常版・Pro版）

Windows の MATLAB R2025b で、MATLAB Runtime を同梱したインストーラーを作り、MATLAB のない PC へ配るまで。

対象：インストーラーを作る担当者配布先：MATLAB なしの Windows PC更新：2026-11-20

現在の状態：ソースとビルドの手順は用意済みです。Windows での実際のビルドと、MATLAB のない PC でのインストールの確認は未実施です。

01

START HERE

目的と対象

この手順書は、Process Insight Tool の Windows 用インストーラーを作る担当者向けです。通常版（配布版）とPro版の2種類を作ります。アプリの使い方は配布版の利用手順書を参照してください。

i

配布先の PC には MATLAB がない前提です

ビルドでは、アプリと MATLAB Runtime（アプリを動かすための無償の部品）を1つにまとめたインストーラーを作ります。利用者はそのインストーラーを実行するだけで使え、MATLAB 本体も、インストール時のインターネット接続も要りません。MATLAB と MATLAB Compiler が必要なのは、ビルドする PC だけです。

版インストーラーアプリの題名内容
通常版（配布版）ProcessInsightTool_Installer.exeProcess Insight Tool学習・比較・保存（汎用回帰は GPR・重回帰・PLS・ランダムフォレスト・バギング木）、データの単変量の傾向のグラフ、推定、SHAP解析（分布図・依存図）、炉内補間、実験計画（評価指標つき）。
Pro版ProcessInsightToolPro_Installer.exeProcess Insight Tool Pro通常版の機能に加えて、Swing Curve学習の周期カーネル（swingperiodic）と周期の探索範囲、レジスト膜厚の SHAP へのカーブ近似、極値・山間／谷間の傾き、近似残差の診断、データのグラフ8種類（ヒストグラム・相関・ANOVA・Parallel Coordinates・Parallel Sets・Sankey・PCA・クラスタリング）、汎用回帰の EBM・XGBoost・LightGBM・CatBoost とハイパーパラメータの探索、拡張実験計画、ワードクラウド。

版はビルドのときに決まります。起動後の設定や引数で通常版を Pro 版へ切り替えることはできません。通常版には Pro 版だけの機能の画面と、そのためのファイルを含めません。

!

この手順書の範囲

ビルドは Windows 64bit の MATLAB R2025b でしか実行できないため、MATLAB の画面の画像は載せていません。操作はコマンドウィンドウへの入力で行います。2026-11-19 時点で、Windows での実際のビルドとインストールは未実施です。最初のビルドでは各章の「確認」を一つずつ確かめ、結果を verification.md に記録してください。

03

OVERVIEW

全体の流れ

1ソースを置く→2環境と Runtime を用意→3通し確認とテスト→4通常版をビルド→5Pro版をビルド→6MATLAB のない PC で確認→7配る

3章のテストに失敗すると、ビルドは自動で止まります。通常版と Pro 版は別々のフォルダに作られるため、順番はどちらが先でもかまいません。

04

STEP 1

ソースを置く

1-1プロジェクトのフォルダを用意する

  1. GitHub の https://github.com/rsakamoto-0824/standalone-analysis-app を開き、Code → Download ZIP でダウンロードします。会社の PC から GitHub を開けない場合は、承認された方法でフォルダ一式を持ち込みます。
  2. ZIP を展開し、フォルダを C:\work\StandaloneAnalysisApp に置きます。

フォルダの場所には、日本語や空白を含まない短いパスを使うことをおすすめします（ビルドの道具が長いパスや日本語のパスで失敗することがあるため）。

確認：C:\work\StandaloneAnalysisApp\build_windows.m と app・core フォルダがあること。

C:\work\StandaloneAnalysisApp\
  app\                 画面のソース（起動口は launch_analysis_app.m）
  core\                学習・保存・検証などの計算
  tests\               単体テストと全機能の通し確認
  samples\             合成サンプル（インストーラーに入れます）
  docs\user-guide\     手順書（インストーラーに入れます）
  build_windows.m      ビルドの入口
  run_tests.m          全テスト
05

STEP 2

環境と MATLAB Runtime を用意する

2-1MATLAB R2025b でフォルダを開き、製品を確認する

MATLAB R2025b を起動し、コマンドウィンドウに次を入力します。

MATLAB コマンドウィンドウ
cd('C:\work\StandaloneAnalysisApp')
setup_paths;
version('-release')
computer('arch')
license('test', 'Compiler')
license('test', 'Statistics_Toolbox')

確認：リリースが 2025b、アーキテクチャが win64、2つの license がどちらも 1 であること。

2-2MATLAB Runtime のインストーラーを用意する（最初に1回）

インストーラーに MATLAB Runtime を入れるため、ビルドする PC に、使っている MATLAB と同じ更新版の MATLAB Runtime インストーラーが必要です。

ビルドする PC方法
インターネットに接続できるコマンドウィンドウで次を実行します。数分かかります。
MATLAB コマンドウィンドウ
compiler.runtime.download
インターネットに接続できない
  1. 上のコマンドを実行すると、接続できないというエラーと一緒に、入手先の URL が表示されます。
  2. インターネットに接続できる PC でその URL からダウンロードし、承認された方法でビルドする PC へ持ち込みます。
  3. MATLAB の 設定 → MATLAB Compiler で、持ち込んだ MATLAB Runtime インストーラーの場所を指定します。

確認：エラーなく終わること（接続できない場合は、設定で場所を指定したこと）。

!

R2025b 以外では止まります

製品のアプリと学習処理は、制御側との互換のため R2025b 以外では起動しません（「MATLAB / MATLAB Runtime R2025b が必要です」と表示）。この確認を外さないでください。

STEP 3

全機能の通し確認とテスト

3-1全機能の通し確認を実行する

MATLAB コマンドウィンドウ
addpath('tests');
results = run_app_flow_check;

アプリを実際に起動し、同梱サンプルで、学習・比較・保存、炉内補間、推定、SHAP解析、実験計画、ワードクラウド、設定、結果の出力、通常版の画面（Pro 版だけの選択肢・説明が出ないこと）、文字の大きさの変更、入力の誤りの自動確認を、画面のボタンと同じ入口から順に確かめます。R2025b では SHAP も実際に計算します。数分かかります。設定とログは一時フォルダへ保存するため、ふだんの設定は変わりません。

確認：最後に「確認 16 件中 16 件成功」と表示されること。失敗した項目は、表の Note の内容を記録します。

3-2全テストを実行する

MATLAB コマンドウィンドウ
results = run_tests;
fprintf('Passed=%d, Failed=%d, Incomplete=%d\n', ...
    sum([results.Passed]), sum([results.Failed]), sum([results.Incomplete]));

学習・保存の正本コードが変わっていないことを照合してから、単体テストを実行します。

確認：Failed=0、Incomplete=0 であること（R2025b ではすべてのテストを実行します）。

07

STEP 4

通常版（配布版）をビルドする

4-1ビルドを実行する

MATLAB コマンドウィンドウ
standard = build_windows('standard');

次の順に自動で進みます。ビルドには十数分以上かかることがあります。途中のメッセージはコマンドウィンドウに表示されます。

  1. R2025b・Windows 64bit・必要な製品を確認します。
  2. 3章の全テストを実行します（失敗するとここで止まります）。
  3. 一時フォルダへソースを写し、Pro 版だけの7ファイルを除いて、版を「通常版」に固定します。
  4. MATLAB Compiler で ProcessInsightTool.exe を作ります（application フォルダ）。サンプルと利用手順書も中に入れます（通常版は利用者向けの user-manual.html と、その画像・スタイルだけを入れ、Pro 版の機能を説明する手順書は入れません）。
  5. MATLAB Runtime を同梱したインストーラー ProcessInsightTool_Installer.exe を作ります（installer フォルダ）。サンプルと手順書もアプリと一緒にインストールされます。
  6. 版の確認用ファイル edition-manifest.json を書きます。

確認：C:\work\StandaloneAnalysisApp\build\windows\standard\installer\ProcessInsightTool_Installer.exe ができていること。

C:\work\StandaloneAnalysisApp\build\windows\standard\
  installer\
    ProcessInsightTool_Installer.exe   ← 配布するもの（MATLAB Runtime を同梱）
  application\
    ProcessInsightTool.exe             exe 本体（インストーラーの中身と同じ）
    readme.txt など                MATLAB Compiler が作る付随ファイル
    samples\                       合成サンプル
    docs\user-guide\               利用手順書（user-manual.html）と、その画像だけ
  edition-manifest.json            版・含めたファイル・バージョンの一覧
i

インストーラーの作成で止まった場合

exe はできていて、MATLAB Runtime のインストーラーが見つからないことが多い原因です。2-2 を済ませてから、もう一度 build_windows を実行してください。インストーラーを作らず exe だけを作るときは build_windows('standard', false) とします（この場合、配布先には MATLAB Runtime を別に入れる必要があります）。

STEP 5

Pro版をビルドする

5-1ビルドを実行する

MATLAB コマンドウィンドウ
pro = build_windows('pro');

次の順に自動で進みます。ビルドには十数分以上かかることがあります。途中のメッセージはコマンドウィンドウに表示されます。

  1. R2025b・Windows 64bit・必要な製品を確認します。
  2. 3章の全テストを実行します（失敗するとここで止まります）。
  3. 一時フォルダへソースを写し、Pro 版だけの機能も含めて、版を「Pro版」に固定します。
  4. MATLAB Compiler で ProcessInsightToolPro.exe を作ります（application フォルダ）。サンプルと利用手順書も中に入れます。
  5. MATLAB Runtime を同梱したインストーラー ProcessInsightToolPro_Installer.exe を作ります（installer フォルダ）。サンプルと手順書もアプリと一緒にインストールされます。
  6. 版の確認用ファイル edition-manifest.json を書きます。

確認：C:\work\StandaloneAnalysisApp\build\windows\pro\installer\ProcessInsightToolPro_Installer.exe ができていること。

Pro版だけに含めるファイル（通常版には含めない）
app/SwingCurveView.m
core/fit_swing_curve.m
core/fit_swing_spline.m
core/swing_curve_values.m
core/swing_curve_extrema.m
core/swing_spline_extrema.m
core/swing_residual_diagnostics.m

このほか、次の画面と説明は Pro 版でだけ表示されます。

  • Swing Curve学習の周期カーネル（swingperiodic）と周期の探索範囲
  • 実験計画作成の拡張 D最適・拡張 I最適（既存の計画に点を追加）と「② 既存の計画」の欄
  • 「10 Help」の Pro 版だけの用語・操作・関数のリンクと、ビルド・利用手順書（procedure-guide.html）を開くボタン

Pro 版のインストーラーには、すべての手順書を入れます。

STEP 6

版の確認と、MATLAB のない PC での確認

6-1版の確認用ファイルを見る

各フォルダの edition-manifest.json をメモ帳で開きます。

版確認すること
通常版"Edition": "standard"、"ProFiles" が空（[]）、"Installer": true であること。
Pro版"Edition": "pro"、"ProFiles" に上の7ファイル、"Installer": true であること。

6-2MATLAB の入っていない PC でインストールして確かめる

利用者と同じ条件で確かめるため、MATLAB も MATLAB Runtime も入っていない Windows PC（検証用の PC や仮想環境）を使います。インターネットに接続しない状態で行うと、利用者の環境に近くなります。

  1. インストーラーをダブルクリックし、案内に従ってインストールします（MATLAB Runtime も一緒に入ります）。
  2. スタートメニューのショートカット（見つからない場合はインストール先の exe）から起動します。初回は時間がかかることがあります。
  3. 画面の題名とホームの見出しが、通常版は「Process Insight Tool（通常版）」、Pro版は「Process Insight Tool Pro（Pro版）」であることを確かめます。
  4. 「1 APC 学習」の サンプルデータを開く でサンプルが開くこと、「10 Help」の 利用者向け手順書を開く で手順書が開くことを確かめます。
  5. 版の違い：「2 Swing Curve学習」の ③ で、Pro版だけカーネルに swingperiodic があり、周期の探索範囲の欄が表示されることを確かめます。モデルを作った後の ④ の SHAP 依存: RESIST_TH で、Pro版だけ膜厚のカーブ近似の設定が表示されます。「7 実験計画作成」の方式に、Pro版だけ「拡張 D最適」「拡張 I最適」があることも確かめます。「10 Help」は、通常版では swingperiodic・拡張実験計画などの用語がなく、手順書のボタンが1つだけであることを確かめます。
  6. サンプルでモデルを学習し、MAT を保存して、保存後検証がすべて成功することを確かめます。
  7. ウィンドウ右上の × で閉じると、アプリが終了することを確かめます。

確認：MATLAB のない PC で、インストールから学習・保存まで動くこと。

利用者へ配る

配る相手渡すもの
一般の利用者ProcessInsightTool_Installer.exe（通常版）と、利用手順書（インストール後は、インストール先の docs\user-guide\user-manual.html からも開けます）
Pro版の利用者ProcessInsightToolPro_Installer.exe（Pro版）と、同じ利用手順書（Pro 版だけの機能はビルド・利用手順書の10章）

TROUBLESHOOTING

困ったとき

「MATLAB / MATLAB Runtime R2025b が必要です」と表示される

ビルドする PC の MATLAB が R2025b ではありません。version('-release') で確認します。インストーラーで入れたアプリでこの表示が出る場合は、R2025b 以外でビルドしたインストーラーを使っていないか確認します。

build_windows:installer で止まる

exe はできていて、MATLAB Runtime のインストーラーが用意できていないことが多い原因です。2-2 の手順で用意してから、もう一度実行します。エラーの詳細も記録してください。

build_windows:wrongPlatform で止まる

Windows 64bit の MATLAB で実行してください。

build_windows:missingToolbox で止まる

MATLAB Compiler または Statistics and Machine Learning Toolbox が入っていないか、ライセンスが使えません。ver で製品を確認し、ライセンスの担当者に相談します。

テストの失敗でビルドが止まる

コマンドウィンドウに表示された失敗したテストの名前と内容を記録します。テストを外してビルドを続けないでください。

ビルドの途中でパスやファイルのエラーが出る

フォルダの場所を、日本語や空白を含まない短いパス（例：C:\work\StandaloneAnalysisApp）に移してやり直します。ウイルス対策ソフトがビルド中のファイルを止めていないかも確認します。空き容量も確認します。

利用者の PC でインストールできない

管理者の権限が必要な場合があります。情報システムの窓口に相談してください。空き容量（数GB）も確認します。

インストールしたアプリが起動しない・すぐ閉じる

インストールが最後まで終わったか（MATLAB Runtime を含む）を確認し、PC を再起動してから試します。それでも起動しない場合は、表示されたエラーの文を記録します。

「サンプルファイルが見つかりません」と表示される

インストール先のフォルダに samples フォルダがあるか確認します。ない場合は、ビルドに使ったソースの samples フォルダを確認してビルドし直します。

Help から手順書が開かない

インストール先の docs\user-guide\user-manual.html を直接ダブルクリックしても開けます。

Pro版の機能が通常版に出る／Pro版に出ない

edition-manifest.json の Edition を確認します。版はビルドのときに決まるため、違っていれば正しい版でビルドし直します。

解決しない場合は、実行したコマンド、表示されたエラーの文、MATLAB のリリースと更新版を記録して開発の担当者へ伝えてください。
