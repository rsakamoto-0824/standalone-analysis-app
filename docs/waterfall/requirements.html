業務目的・対象機能・品質要求・受入条件を定める。

業務目的・対象機能・品質要求・受入条件を定める。

製品：Process Insight Tool。基準コミット：df9ffc2214c6196eefb389f890d25551d53f2b1d。文書の版と製品バージョンは別管理です。

目的と利用場面

成膜・露光プロセスの担当者が、CSV / Excelの計測値からモデルを比較し、未計測位置の予測、変数の影響の把握、実験計画を行うローカル解析アプリです。設備へ予測値を自動適用する制御接続は対象に含めません。

場面成果
露光APC4変数から学習し、検証したGPRのMATを制御側の確認へ渡す。
Swing Curve膜厚と下地の関係を学習して、予測・誤差・入力の寄与を確認。
LP-CVDRunごとの計測Slotから膜厚・屈折率を補間。
解析・計画共通分割比較、重要度、データの傾向、実験計画の評価を確認。

既存の面内モデルの推定は互換用途で残します。面内モデルを新しく学習する画面はありません。

機能要求

要求ID対象現行要件試験仕様
R-001ファイル入力CSV / Excelのシートとヘッダー行を指定し、先頭100行を表示する。空欄・重複ヘッダーを拒否し、元ファイル行番号を保持する。T-01
R-002変数の指定目的変数1〜20列を独立したモデルで処理する。説明変数との重複・列の再使用・非数値・欠損・Infを理由と元行付きで拒否する。T-02
R-003APC学習SIN_TH → SIN_RN → NSG_TH → RESIST_THの順でGPRを学習。25行未満は停止、25〜149行は注意とする。T-03
R-004Swing Curve学習下地なしは膜厚だけ、下地ありは追加説明変数と最後にRESIST_THを使用する。膜厚・下地の入力列を変更できる。T-04
R-005汎用回帰学習GPR・重回帰・PLS・ランダムフォレスト・バギング木を選択し、複数条件で比較する。PLS成分数・木の本数を指定できる。T-05
R-006評価と比較学習データ評価を初期値とし、任意で共通分割の交差検証を行う。目的変数ごとに順位付けし、R²・RMSEを画面へ表示する。T-06
R-007指標と要約8評価指標と列の要約を各評価で計算する。決定係数と相関係数の2乗を区別し、未定義値は理由を表示する。KL / MIビン数は設定だけで変更する。T-07
R-008選択モデル保存学習・任意のSHAP評価・比較後に、選択した全行学習モデル1つだけを再学習せずMATへ保存し、保存前後を検証する。T-08
R-009推定・SHAP保存MATと起動中のモデルを同じ画面で使用できる。実測列は任意。SHAPを省略・再計算でき、分布と依存図をアプリ内に表示する。T-09
R-010結果出力元行・入力・実測・予測・残差・SHAPを1表でCSV / Excelへ保存する。グラフのPNG保存・クリップボードコピー、任意列での色指定を提供する。T-10
R-011炉内補間WaferId・BoatSlot・複数目的変数・任意のバッチからRun別に分離し、スプライン・3次多項式・RBF・3種類のGPRを比較する。T-11
R-012炉内検証・保存内部Slotの留め置き検証、目的変数ごとのRMSE棒グラフ、外挿の明示、選択したFurnace_Modelの保存・再読込みを提供する。T-12
R-013実験計画D最適・I最適・同一水準の直交表（2〜5水準）、交絡、D/A/I/G/VIF等を表示する。初期実験数25、seedは設定だけで指定する。T-13
R-014変数重要度Permutation ImportanceとPLSのVIPを結果へ表示し、SHAPとは別の指標として説明する。T-14
R-015データの傾向学習前に選択列の単変量の傾向をグラフと要約で確認でき、数値列・カテゴリ列で色を指定できる。T-15
R-016設定・Help保存先・テーマ・文字サイズ・GPR Fit method・ビン数・DOE seed・RBF幅と正則化を保存する。用語と公式関数ヘルプを表示する。T-16

非機能・品質要求

要求ID対象現行要件試験仕様
R-017操作と表示進捗・中止・エラーをアプリ内へ表示し、リサイズに対応する。学習履歴は設定変更後も保持する。T-17
R-018Windows配布Windows 64bit / R2025bを対象に、ProcessInsightTool.exeとRuntime同梱インストーラーを作成する。T-18
R-019データ管理・互換性処理はローカル。モデルの学習値を入力と同じ管理区分で扱う。GPRの保存契約と旧モデルの互換確認、許可項目だけの運用ログを維持する。T-19
品質条件
環境Windows 64bit、MATLAB / Runtime R2025b。開発環境の補助確認を対象環境の受入へ読み替えない。
性能保証値は未合意。入力件数・条件数・CV・SHAPの有無と実測時間を記録。
機密性解析はローカル。MAT・実入力・ログ・記入済み承認記録を管理する。
再現性比較の分割・DOEのseedと条件を記録。全GPR学習で常に同一結果を保証しない。
保守性画面・計算・保存・試験を分離し、MAT契約と正本を照合。

上限と保留事項

項目条件
学習目的変数最大20列、目的変数×条件は100組まで。自動SHAPは先頭最大1000行。
炉内Run・項目あたり計測5〜300点。最大100バッチ・20目的変数・生成2000点、出力20万行・学習2万回。
実験計画1〜8因子、2〜5水準、実験数1〜300。混合水準直交表は対象外。
対象外クラウド保存、アカウント管理、設備への自動制御接続、解析結果の業務上の自動承認。
保留旧制御側入力・精度閾値・処理時間目標・保存期間等は係長確認と課長承認で確定。

実装根拠：core/model_constants.m、core/furnace_constants.m、core/create_experiment_design.m

受入条件

全要求に試験を対応付け、Windows R2025b / Runtimeと利用者の代表データで確認します。精度の合格値は目的変数・単位・範囲ごとに合意し、一律のRMSE閾値を作りません。試験結果・品質評価書に証跡を記録し、係長確認と課長の承認を得て受入・配布を判断します。
