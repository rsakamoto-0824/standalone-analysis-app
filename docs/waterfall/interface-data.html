データ・外部インターフェース仕様書

入力列・出力項目・MAT保存・設定とログの形式を定める。

基準：df9ffc2 ／ 現行実装を文書化した初版。Windows R2025b／Runtimeの受入は未完了です。

入力列・出力項目・MAT保存・設定とログの形式を定める。

製品：Process Insight Tool。基準コミット：df9ffc2214c6196eefb389f890d25551d53f2b1d。文書の版と製品バージョンは別管理です。

入力仕様

用途必須項目検証
共通CSV / Excel、シート、ヘッダー行、列名、データ行一意で空欄でないヘッダー。SourceRowを保持。
APC4変数へ割り当てる数値列＋目的変数説明変数と応答の重複なし。列順固定。
Swing Curve膜厚（nm）・必要な下地列・目的変数下地なしは膜厚だけ。最後のモデル入力名はRESIST_TH。
汎用回帰数値の説明変数と目的変数有限値・一意な入力列と順序。
炉内WaferId・正整数BoatSlot・計測列・任意バッチRun内WaferIdとSlot重複不可。計測列の空欄だけは未計測。バッチなしは全行1Run。

実装根拠：core/read_input_data.m、core/modeling_input_data.m、core/prepare_furnace_data.m

モデル保存契約

対象MAT変数保持するもの読込み
GPRTrain_Modelのみ完全なRegressionGP、X・入力名・ResponseName・学習属性。compact化しない。load_train_model / load_analysis_model。旧制御側は互換確認が必要。
重回帰・PLS・木Regression_ModelのみVersion=1のProcessRegressionModel、Method・入力名・X/Y・係数またはEnsemble等。load_analysis_model / predict。必要なcoreクラスを使用。
炉内補間Furnace_Modelのみ選択Run・目的変数・方式・計測値・Slot・元行・設定・学習器。load_furnace_model / predict_furnace_model。推定・SHAPのMATとは別。

初期名はTrain_Model_目的変数.mat、SwingCurve_Model_目的変数.mat、GenericGPR_Model_目的変数.mat、汎用クラスはGenericRegression_Model_目的変数.mat、炉内はFurnaceInterpolation_Model_…matです。目的変数名をファイル名へ付けてもResponseNameを勝手に変更しません。

保存時は既に学習済みの1モデルを再学習せず保存し、変数・属性・学習データと予測の一致を検証します。MATは学習値を含み、入力と同じ管理区分で扱います。

実装根拠：core/save_train_model.m、core/save_regression_model.m、core/save_furnace_model.m、core/load_analysis_model.m、core/default_model_filename.m

表と画像の出力

出力項目と規則
予測・SHAPの1表SourceRow、元説明変数、任意の実測、予測、残差（実測−予測）、SHAP。列名重複時は番号で区別。
未計算SHAP先頭M行だけ計算したとき、残りはNaN。寄与0とは区別。
比較・指標目的変数、条件、Scope、指標、成否とNote等。
炉内予測Run・目的変数・方式、Slot・WaferId・元行、予測と区間・外挿。生成SlotのWaferIdは空欄。
PNG・コピー表示中または選択したグラフの画像。モデルや数値データの代わりではない。

実装根拠：core/combine_model_outputs.m、core/write_result_table.m、core/predict_furnace_model.m

設定JSON

設定はprefdir/StandaloneAnalysisApp/settings.json。Windowsの実ユーザー名を固定した絶対パスは作りません。許可項目だけを保存し、一時ファイルから置換します。

項目初期値条件
SaveFolder / Theme / FontSize起動フォルダ／ライト／12存在するフォルダ、ライト／ダーク、8〜20整数。
Kernel / SwingKernel / FitMethodsquaredexponential／squaredexponential／exactFit methodはexact・sd・sr・fic。新しいGPR学習へ反映。
InputCount / Bins4 / 0入力1〜100。ビン数0（自動）または2〜1000。
Factors / Runs / Seed3 / 25 / 42因子1〜8、実験数1〜300、seed 0〜2³²−1。比較用の初期seed 0とは別。
RBFWidth / RBFRidge / ShowPlots0 / 1e−8 / true幅0は自動、正則化1e−12〜1、SHAP図表示等の既定。

実装根拠：core/app_settings.m、app/SettingsPage.m

運用ログと外部連携

prefdir/StandaloneAnalysisApp/logs/training.jsonlへ追記します。日時（JST）、Function・InputFile・Rows・Kernel・FitMethod・SavePath・Verification・PredictorNames・ResponseName・Status・ElapsedSeconds・Folds・Seedの許可項目を記録します。X/Y値そのものは書きませんが、ファイル名や保存先は含みます。

設備・DB・外部解析API・自動更新・ログ送信は対象外です。Helpの外部リンクは利用者が開く操作です。ログの保管期間と削除担当は運用レビューで決定します。

実装根拠：core/write_training_log.m
