設定・ログ

AnalysisControllerが設定、ページ遅延生成、ダイアログ、計算サービス、起動中のモデルをまとめます。各機能はPageクラス、共通表示はAppPage、モデル共有はModelStoreが担当します。計算関数は画面から分離し、試験ではサービスを置換できます。

実装根拠：app/AnalysisController.m、app/AppPage.m、app/ModelStore.m

学習と保存の処理順

①データを開く②変数を選ぶ③条件を決めて実行④結果を比べて保存

実行時に入力を検証し、不正なら②へ戻して理由を表示します。目的変数ごとに独立したモデルを作ります。CVなしを初期値とし、利用者が選んだときに未学習行を予測する共通分割の検証を行います。SHAPは省略・後計算が可能。保存は選択した全行学習モデルだけを対象とし、再学習しません。

部品間の境界

部品責務境界
DataSourceControl / ColumnMapperファイル、シート、ヘッダー、列の順序と選択数値検証は実行前にcoreへ。
ModelingPage / ResultPanel条件・進捗・順位・評価・選択保存計算はevaluate_modeling_batch、共有はModelStore。
DataExplorer / EvaluationScatterView傾向と予実・残差の表示色の変更はモデルや精度を変えない。
FurnacePageRun別・目的変数別の補間と保存専用Furnace_Modelを使用。
ModelUsePage保存／起動中モデルの推定とSHAPPredictorNamesと入力順を維持。
SettingsPage / HelpPage設定と用語・手順Fit method・ビン数・seed・RBFは設定で編集。

環境と外部境界

製品はWindows 64bit / R2025bを対象とします。解析のネット送信やDB接続は持たず、ローカルファイルで入出力します。Helpの公式リンクを利用者が開く場合は外部サイトへ移動します。設定と運用ログは端末のprefdir配下です。保存契約はデータ・外部インターフェース仕様書で定義します。
