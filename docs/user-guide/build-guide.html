BUILD GUIDE

Process Insight Tool
ビルド手順書（通常版・Pro版）

Windows の MATLAB R2025b で、通常版（配布版）と Pro 版の exe を作り、利用者へ配るまで。

対象：exe を作る担当者環境：Windows 64bit / R2025b更新：2026-11-18

現在の状態：ソースとビルドの手順は用意済みです。Windows での実際のビルドと、Runtime だけの PC での確認は未実施です。

01

START HERE

目的と対象

この手順書は、Process Insight Tool の Windows 用の実行ファイル（exe）を作る担当者向けです。通常版（配布版）とPro版の2種類を作り、MATLAB 本体のない利用者の PC へ配る準備までを説明します。アプリの使い方は配布版の利用手順書を参照してください。

版実行ファイル画面の題名内容
通常版（配布版）ProcessInsightTool.exeProcess Insight Tool学習・比較・保存、推定、SHAP解析（分布図・依存図）、炉内補間、実験計画、ワードクラウド。
Pro版ProcessInsightToolPro.exeProcess Insight Tool Pro通常版の機能に加えて、レジスト膜厚の SHAP へのカーブ近似（三角関数・スプライン）、極値・山間／谷間の傾き、近似残差の診断。

版はビルドのときに決まります。起動後の設定や引数で通常版を Pro 版へ切り替えることはできません。通常版の exe には、Pro 版だけの機能のファイルを含めません。

!

この手順書の範囲

ビルドは Windows 64bit の MATLAB R2025b でしか実行できないため、この手順書には MATLAB の画面の画像を載せていません。操作はコマンドウィンドウへの入力で行います。2026-11-18 時点で、Windows での実際のビルドは未実施です。最初のビルドでは、各章の「確認」を一つずつ確かめ、結果を verification.md に記録してください。

03

OVERVIEW

全体の流れ

1ソースを置く→2環境を確認→3通し確認とテスト→4通常版をビルド→5Pro版をビルド→6版と起動を確認→7配る

3章のテストに失敗すると、ビルドは自動で止まります。通常版と Pro 版は別々のフォルダに作られるため、順番はどちらが先でもかまいません。

04

STEP 1

ソースを置く

1-1プロジェクトのフォルダを用意する

  1. GitHub の https://github.com/rsakamoto-0824/standalone-analysis-app を開き、Code → Download ZIP でダウンロードします。会社の PC から GitHub を開けない場合は、承認された方法でフォルダ一式を持ち込みます。
  2. ZIP を展開し、フォルダを C:\work\StandaloneAnalysisApp に置きます。

フォルダの場所には、日本語や空白を含まない短いパスを使うことをおすすめします（ビルドの道具が長いパスや日本語のパスで失敗することがあるため）。

確認：C:\work\StandaloneAnalysisApp\build_windows.m と C:\work\StandaloneAnalysisApp\app・C:\work\StandaloneAnalysisApp\core フォルダがあること。

C:\work\StandaloneAnalysisApp\
  app\                 画面のソース（起動口は launch_analysis_app.m）
  core\                学習・保存・検証などの計算
  tests\               単体テストと全機能の通し確認
  samples\             合成サンプル（exe と一緒に配ります）
  docs\user-guide\     手順書（exe と一緒に配ります）
  build_windows.m      ビルドの入口
  run_tests.m          全テスト
05

STEP 2

環境を確認する

2-1MATLAB R2025b でフォルダを開き、製品を確認する

MATLAB R2025b を起動し、コマンドウィンドウに次を入力します。

MATLAB コマンドウィンドウ
cd('C:\work\StandaloneAnalysisApp')
setup_paths;
version('-release')
computer('arch')
license('test', 'Compiler')
license('test', 'Statistics_Toolbox')

確認：リリースが 2025b、アーキテクチャが win64、2つの license がどちらも 1 であること。

!

R2025b 以外では止まります

製品のアプリと学習処理は、制御側との互換のため R2025b 以外では起動しません（「MATLAB / MATLAB Runtime R2025b が必要です」と表示）。この確認を外さないでください。

06

STEP 3

全機能の通し確認とテスト

3-1全機能の通し確認を実行する

MATLAB コマンドウィンドウ
addpath('tests');
results = run_app_flow_check;

アプリを実際に起動し、同梱サンプルで、学習・比較・保存、炉内補間、推定、SHAP解析、実験計画、ワードクラウド、設定、結果の出力、入力の誤りの検出を、画面のボタンと同じ入口から順に確かめます。R2025b では SHAP も実際に計算します。数分かかります。設定とログは一時フォルダへ保存するため、ふだんの設定は変わりません。

確認：最後に「確認 15 件中 15 件成功」と表示されること。失敗した項目は、表の Note の内容を記録します。

3-2全テストを実行する

MATLAB コマンドウィンドウ
results = run_tests;
fprintf('Passed=%d, Failed=%d, Incomplete=%d\n', ...
    sum([results.Passed]), sum([results.Failed]), sum([results.Incomplete]));

学習・保存の正本コードが変わっていないことを照合してから、単体テストを実行します。

確認：Failed=0、Incomplete=0 であること（R2025b ではすべてのテストを実行します）。

07

STEP 4

通常版（配布版）をビルドする

4-1ビルドを実行する

MATLAB コマンドウィンドウ
standard = build_windows('standard');

次の順に自動で進みます。

  1. R2025b・Windows 64bit・必要な製品を確認します。
  2. 3章の全テストを実行します（失敗するとここで止まります）。
  3. 一時フォルダへソースを写し、Pro版だけの7ファイルを除いて、版を「通常版」に固定します。
  4. MATLAB Compiler で ProcessInsightTool.exe を作ります。
  5. exe と同じフォルダへ、サンプル（samples）と手順書（docs\user-guide）を置き、版の確認用ファイル edition-manifest.json を書きます。

ビルドには数分から十数分かかります。途中のメッセージはコマンドウィンドウに表示されます。

確認：C:\work\StandaloneAnalysisApp\build\windows\standard\ProcessInsightTool.exe ができていること。

C:\work\StandaloneAnalysisApp\build\windows\standard\
  ProcessInsightTool.exe
  readme.txt など       MATLAB Compiler が作る付随ファイル
  edition-manifest.json 版と含めたファイルの一覧
  samples\             合成サンプル（ProcessInsight_Samples.xlsx ほか）
  docs\user-guide\     利用手順書（user-manual.html）ほか

STEP 6

版と起動を確認する

6-1版の確認用ファイルを見る

各フォルダの edition-manifest.json をメモ帳で開きます。

版確認すること
通常版"Edition": "standard" で、"ProFiles" が空（[]）であること。
Pro版"Edition": "pro" で、"ProFiles" に上の7ファイルがあること。

6-2ビルドした PC で起動する

  1. エクスプローラーで出力フォルダを開き、exe をダブルクリックします。初回は起動に時間がかかることがあります。
  2. 画面の題名が、通常版は「Process Insight Tool」、Pro版は「Process Insight Tool Pro」であることを確かめます。ホーム画面の見出しにも「通常版」「Pro版」と表示されます。
  3. 「1 APC 学習」の サンプルデータを開く でサンプルが開くこと、「10 Help」の 利用者向け手順書を開く で手順書が開くことを確かめます。
  4. 版の違い：「2 Swing Curve学習」でモデルを作り、④ の SHAP 依存: RESIST_TH を開きます。Pro版だけ、膜厚のカーブ近似の設定（近似方式・周期など）が表示されます。
  5. ウィンドウ右上の × で閉じると、アプリが終了することを確かめます。

確認：両方の版が起動し、題名と機能の違いが上のとおりであること。

10

STEP 7

利用者へ配る

7-1配るものをまとめる

  1. 配る版のフォルダ（build\windows\standard または build\windows\pro）を、中身ごとまとめます。exe だけを抜き出さないでください。
  2. エクスプローラーでフォルダを右クリックし、ZIP ファイルに圧縮する で1つのファイルにします。
  3. MATLAB Runtime R2025b（Windows 64bit）のインストーラーを、MathWorks の配布ページから入手します。ビルドに使った MATLAB と同じ更新版、またはそれ以降の更新版を選びます。
配る相手渡すもの
一般の利用者通常版のフォルダ（ZIP）、MATLAB Runtime R2025b、利用手順書（フォルダの docs${BACKSLASH}user-guide${BACKSLASH}user-manual.html）
Pro版の利用者Pro版のフォルダ（ZIP）、MATLAB Runtime R2025b、同じ利用手順書（Pro版だけの機能はビルド・利用手順書の10章）

7-2利用者の PC での準備（担当者または利用者）

  1. MATLAB Runtime R2025b をインストールします（管理者の権限が必要な場合があります）。
  2. ZIP を、日本語や空白を含まない場所（例：C:\Apps\ProcessInsightTool）に展開します。
  3. フォルダの中の exe をダブルクリックして起動します。デスクトップにショートカットを作る場合は、ショートカットの「作業フォルダー」を exe のフォルダにします（サンプルと手順書を exe のフォルダから探すため）。

確認：MATLAB 本体のない PC で起動し、ホーム画面が表示されること。

!

「Windows によって PC が保護されました」と表示された場合

インターネットから入手した、署名のない exe で表示されることがあります。実行してよいかは、会社の情報システムのルールに従ってください。

TROUBLESHOOTING

困ったとき

「MATLAB / MATLAB Runtime R2025b が必要です」と表示される

MATLAB（またはRuntime）が R2025b ではありません。ビルドする PC は version('-release') で、利用者の PC は入れた Runtime のリリースを確認します。

build_windows:wrongPlatform で止まる

Windows 64bit の MATLAB で実行してください。Mac や Linux では Windows 用の exe は作れません。

build_windows:missingToolbox で止まる

MATLAB Compiler または Statistics and Machine Learning Toolbox が入っていないか、ライセンスが使えません。ver で製品を確認し、ライセンスの担当者に相談します。

テストの失敗でビルドが止まる

コマンドウィンドウに表示された失敗したテストの名前と内容を記録します。テストを外してビルドを続けないでください。

ビルドの途中でパスやファイルのエラーが出る

フォルダの場所を、日本語や空白を含まない短いパス（例：C:\work\StandaloneAnalysisApp）に移してやり直します。ウイルス対策ソフトがビルド中のファイルを止めていないかも確認します。

exe が起動しない・すぐ閉じる

利用者の PC に MATLAB Runtime R2025b が入っているか、更新版がビルドに使った MATLAB と同じかそれ以降かを確認します。フォルダの中身をすべてコピーしたかも確認します。

「サンプルファイルが見つかりません」と表示される

exe と同じフォルダに samples フォルダがあるか確認します。ショートカットから起動した場合は、ショートカットの「作業フォルダー」を exe のフォルダにします。

Help から手順書が開かない

exe と同じフォルダに docs\user-guide\user-manual.html があるか確認します。直接ダブルクリックしても開けます。

Pro版の機能が通常版に出る／Pro版に出ない

edition-manifest.json の Edition を確認します。版はビルドのときに決まるため、違っていれば正しい版でビルドし直します。

解決しない場合は、実行したコマンド、表示されたエラーの文、MATLAB / Runtime のリリースと更新版を記録して開発の担当者へ伝えてください。
